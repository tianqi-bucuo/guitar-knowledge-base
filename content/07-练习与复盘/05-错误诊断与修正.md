# 错误诊断与修正

## 学习目标与先修知识

本页标题中的“诊断”只指音乐任务排错，不是医学诊断。你将区分现象、假设、改动与结果，并在超出自助边界时停止或求助。先修 [[07-练习与复盘/04-练习日志模板|练习日志模板]] 和 [[07-练习与复盘/01-有效练习流程|有效练习流程]]，先能保存材料、条件及修正证据。

> 安全边界：本页只提供一般性音乐练习与复盘信息，不用于诊断、治疗或康复。弹奏出现疼痛、麻木或针刺感、无力、肿胀、动作控制下降、过度疲劳或明显不适时立即停止；症状持续、反复或加重时，请向合格医疗专业人士求助。[^safety-bapam]

## 核心概念

“转换处口数停了，下一和弦晚进入”是现象；“注意力转向左手”是待验证假设；“先口数再带入转换”是改动。不要把三者合成“我没有节奏感”。错误管理的概念综述认为有信息量的反馈与修正能组织错误处理，但不证明本站故障树优于其他方法。[^error-frontiers]

本站六步是：捕捉现象 → 定位位置/条件 → 归入暂定错误域 → 写可检验假设 → 只改一个主要变量 → 比较证据并保留/换假设/求助。一次只改一个主要变量是因果比较规则，真实演奏有多个因素，错误域也可能重叠；暂定分类不是永久能力判断。

录音只是额外观察视角。2025 年进阶钢琴学生研究中若干自评改变，而外部专家评分无显著效果，不能把回放叫作客观真相或吉他改善保证。[^audio-feedback-frontiers] 录音可选，不要求上传；设备、位置与注意力都会影响你能听到什么，证据不清楚时先标为未确定。

## 图示与操作步骤

下表是本站原创记录工具，只为安全的音乐任务比较使用。

| 现象 | 出现位置或条件 | 暂定错误域                                                      | 可检验假设 | 单一改动 | 观察结果 | 决策                        |
| ---- | -------------- | --------------------------------------------------------------- | ---------- | -------- | -------- | --------------------------- |
|      |                | 节拍 / 音高和弦 / 音色杂音 / 转换协调 / 结构记忆 / 器材身体边界 |            |          |          | 保留 / 换假设 / 求助 / 停止 |

先按六步写现象与位置，再选暂定错误域。节拍看口数和 click；音高/和弦核对目标关系；音色/杂音核对目标弦；转换/协调看动作衔接；结构/记忆看段落位置；器材/身体边界先判断是否超出自助范围。写出支持与不支持假设时各会看到什么，再改变主要变量，保留其余观察条件。

比较后只保留被证据支持的修正；未支持就换假设，条件不同则先补基线。偶发 slip 可以记录条件，但不能永久化成“能力差”。无法定位时请合格教师协助音乐任务观察，不把增加练习量当万能答案。

身体警讯不进入复现实验，不为了重现现象继续弹。怀疑器材设置时只记录可观察现象，不调整琴颈/弦距，查阅保养与排错页面或请合格维修人员处理。停止练习与求助的判断见 [[08-保养安全与排错/01-疼痛疲劳与停止练习边界|疼痛疲劳与停止练习边界]]；医疗问题向合格医疗专业人士求助，教师与维修人员不代替医疗判断。

## 常见错误及修正

- 用人格标签：改写为可听见或看见的现象与条件。
- 一次改多项：只选一个主要变量，并记录其他变化。
- 只在成功时停止观察：同时留下不支持假设的结果。
- 为了重现而忍痛：直接停止，警讯不参加技术实验。
- 把偶发 slip 永久化：保留条件，另行观察，不评判天赋。

## 分级练习

### 第一级：写现象与条件

把模糊抱怨改写成现象加条件，选择暂定错误域。能区分观察与解释、排除身体警讯，才进入假设比较。

### 第二级：比较竞争假设

为同一现象写两个竞争假设，每次只验证一个。节拍、音色、动作或结构退化时退阶或换策略，身体状态下降即停止。

### 第三级：保留修正证据

用日志或可选录音比较修正前后。证据不支持就换假设而非加量；无法定位、超过器材观察边界或出现安全警讯时求助。

## 自我检查标准

- 我能分别指出现象、假设、改动与结果，不把推测当事实。
- 我能说出什么观察会否定当前假设，并保留不成功的证据。
- 我能在身体警讯出现时停止，不尝试复现疼痛。
- 我能区分音乐教师、维修人员与医疗专业人士的求助边界。
