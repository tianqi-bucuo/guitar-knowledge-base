# 阶段测验

这是自我复盘 checkpoint，不是等级考试、资格认证、医疗/职业能力判断；没有总分和证书。结果只帮助选择下一步，不把当前表现汇总成人的永久能力。

## 学习目标与先修知识

先修 [[07-练习与复盘/05-错误诊断与修正|错误诊断与修正]]、[[05-弹唱与伴奏/08-完整歌曲编配流程|完整歌曲编配流程]] 与 [[06-基础乐理与指板/08-顺阶和弦与级数|顺阶和弦与级数]]。你将准备材料与观察条件，完成整合呈现，并把具体弱项转为专项课程与日志下一步。

> 安全边界：本页只提供一般性音乐练习与复盘信息，不用于诊断、治疗或康复。弹奏出现疼痛、麻木或针刺感、无力、肿胀、动作控制下降、过度疲劳或明显不适时立即停止；症状持续、反复或加重时，请向合格医疗专业人士求助。[^safety-bapam]

## 核心概念

ABRSM 评价同时关注 Pitch、Time、Tone、Shape、Performance；不能只数正确音。下方五维观察表受该多维原则启发，但为本站原创，不复制官方分数或逐项 rubric。[^assessment-abrsm] 材料只用仓库已有原创练习，或自己的原创、公版/合法取得材料；页面不列真实歌曲、歌词、旋律、TAB 或完整曲谱。

录音是可选证据，不要求上传；无法或不愿录音时，可由可信教师或同伴按同一观察表记录。2025 年进阶钢琴研究中若干自评改变，而外部专家评分无显著效果，回放只是有限观察视角，不是客观裁判。[^audio-feedback-frontiers] 单次表现也不能代替日常日志；自我调节研究的练前、练中、练后概念提醒我们保留条件和下一步，而非只留结果标签。[^ommp-frontiers]

## 图示与操作步骤

先声明材料、调/和弦、动作、点击模式、自填速度或不适用与观察方式，再按站准备。呈现中遇失误先尝试回到脉冲，安全警讯直接停止；不要为追求完美中途重来。

| 测验站     | 材料                                         | 主要观察                                  |
| ---------- | -------------------------------------------- | ----------------------------------------- |
| 准备与安全 | 标准调音、持琴与自选起点                     | 调音、姿势、无警讯、能说明停止边界        |
| 和弦与转换 | 本站原创 `C–Am–F–G` 进行                     | 和弦清楚、转换不丢当前脉冲                |
| 节奏       | 已学四四拍与六八拍原创口数/动作              | 拍号分组、细分、重音与 click 相位         |
| 演奏技巧   | 已学分解和弦加一项自选技巧                   | 音色、非目标弦控制、动作舒适              |
| 编配呈现   | 本站原创八小节编配                           | 调/和弦记录、段落对比、完整呈现与失误恢复 |
| 乐理与复盘 | 把上述材料写成音名、和弦构成或级数并填写日志 | 理论映射、错误证据、下一步选择            |

| 观察维度       | 当前项稳定                       | 带条件继续                     | 回到专项                     |
| -------------- | -------------------------------- | ------------------------------ | ---------------------------- |
| 音高与和弦     | 目标音/和弦可辨，错误能定位      | 偶发错误可恢复并记录           | 反复错位且无法定位           |
| 时间           | 脉冲与分组保持，click 回来能核对 | 某段漂移但可退阶恢复           | 口数、动作与 click 持续分离  |
| 音色与控制     | 目标弦清楚，力度变化不靠挤压     | 某技巧音色不稳但基本任务可保留 | 杂音/闷音遮蔽主要结果        |
| 结构与表达     | 段落、重音或伴奏差异可听辨       | 结构正确但对比不足             | 无法说明或保持段落结构       |
| 完整呈现与恢复 | 失误后能回到脉冲并完成           | 需降低复杂度才可完成           | 失误后无法恢复或身体警讯出现 |

- `当前项稳定`：当前材料与记录条件下达到所有可观察项，可继续下一主题；不是永久掌握。
- `带条件继续`：保留已稳定项，同时把一个具体弱项写入日志。
- `回到专项`：链接对应 canonical 课程，不以额外时长惩罚。
- `停止并求助`：出现安全警讯或超出自助/器材观察边界；它不是低分等级，并覆盖其他结果。

## 常见错误及修正

- 只数错音：补上时间、控制、结构和恢复的观察。
- 用未声明速度比较或临时换材料：先保存条件，不同条件不直接判高低。
- 把一次表现当永久能力：结果只描述当前材料与状态。
- 汇总成伪精确总分：逐项说明证据与下一步，不排名。

## 分级练习

### 第一级：准备观察条件

按表准备材料，不演奏也能说出每站证据，能说明安全停止边界再进入呈现。

### 第二级：完整呈现与记录

完成不间断呈现并按五维表记录，不中途追求完美重来。节拍、音色、动作或结构退化就回到上一层或降低复杂度；身体状态下降即停止。

### 第三级：选择专项下一步

把最具体的一项弱点转成日志下一步，并链接 canonical 课程。一次只改一个主要变量是因果比较规则，真实演奏仍含多项因素；证据不清楚先换观察方式，不靠额外重复顶过去。

## 自我检查标准

- 我能为每个结果给出位置、条件与可观察证据。
- 我能指出稳定项与一个具体弱项，并写出下次起点。
- 我能说明录音可选且有限，不把它当永久能力证明。
- 我能优先执行停止并求助，不给自己制造总分、排名或证书。
