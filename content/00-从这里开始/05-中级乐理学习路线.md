# 中级乐理学习路线

## 适用对象

这条路线面向已经能读基础和弦图、完成简单节奏练习，并希望理解“为什么这些音与和弦这样组织”的学习者。它复用知识库中的完整课程，不在路线页重复教材。你可以并行学习阶段一与阶段二；从阶段三开始按先修关系推进，最后在阶段六汇合。

## 导航方法

每个阶段都包含入口、产出与回退点。先读课程，再完成同页R1／D1／A1和答案核对；只有关键词眼熟不算完成。遇到困难时回到列出的具体课程，而不是把整条路线从头重来。

阶段一与阶段二可并行；阶段三以后按先修推进。链接表示推荐学习和回退关系，页面frontmatter中的先修才是理解当前课真正必需的知识。

## 有序链接

1. 从[[03-节奏系统/01-节拍拍号与小节|节拍拍号与小节]]建立读谱与节奏线。
2. 从[[06-基础乐理与指板/01-音高音名与唱名|音高音名与唱名]]建立音高与指板线。
3. 在[[06-基础乐理与指板/12-小调音阶|小调音阶]]处进入完整调性体系。
4. 用[[06-基础乐理与指板/16-七和弦构成|七和弦构成]]连接和弦组成与符号。
5. 用[[06-基础乐理与指板/19-和声功能|和声功能]]进入带语境的进行分析。
6. 在[[05-弹唱与伴奏/11-乐句分析与编配实战|乐句分析与编配实战]]汇合，并到[[07-练习与复盘/07-中级乐理综合测验|综合测验]]复盘。

## 阶段一：读谱与节奏

目标是从“跟着扫”进入“能核算何时起音、持续多久、如何分组”。

1. [[03-节奏系统/01-节拍拍号与小节|节拍拍号与小节]]：区分拍号上、下数字，核对3/4与6/8的主拍组织。
2. [[03-节奏系统/03-四分八分与十六分音符|四分八分与十六分音符]]：建立相对时值与细分。
3. [[03-节奏系统/10-休止附点与延音线|休止附点与延音线]]：区分静默、延长与重新起音。
4. [[03-节奏系统/12-连音与节奏分组|连音与节奏分组]]：处理三连音、复拍子正常三分与符杠分组。
5. [[03-节奏系统/11-切分节奏入门|切分节奏入门]]、[[03-节奏系统/09-六八拍伴奏|六八拍伴奏]]：把读法转成可执行动作。

阶段产出：能把一个小节写成带起拍和时值的事件表，证明总时值正确，并在6/8中按3+3而非六个同等主拍朗读。若休止后总时值少了，回退“休止附点与延音线”；若把6/8普通八分误叫三连音，回退“连音与节奏分组”。

## 阶段二：音高、指板与音程

目标是同时保留音名字母、升降号、八度、指板位置与音程性质。

1. [[06-基础乐理与指板/01-音高音名与唱名|音高音名与唱名]]与[[06-基础乐理与指板/10-五线谱简谱与六线谱|五线谱简谱与六线谱]]：建立实响音区和三种记法的对应。
2. [[06-基础乐理与指板/02-指板上的音名|指板上的音名]]：从标准定弦推0–12品与跨弦同音。
3. [[06-基础乐理与指板/03-全音与半音|全音与半音]]：区分半音数相同与字母拼写相同。
4. [[06-基础乐理与指板/04-指板记忆方法与训练|指板记忆方法与训练]]：用六、五弦锚点、八度关系与双向混合检索建立即时定位能力。
5. [[06-基础乐理与指板/05-音程入门|音程入门]]、[[06-基础乐理与指板/11-音程转位与复音程|音程转位与复音程]]：先数度数，再算性质和半音，最后处理转位与跨八度。

阶段产出：能解释C4–D♯4与C4–E♭4为何半音数相同而度数不同，并完成指定位置到音名、指定音名到多个位置的双向检索。若只能从空弦逐品数，回退“指板记忆方法与训练”；若只会数品格不会拼字母，回退“全音与半音”；若跨八度后只写“2度”，回退“音程转位与复音程”。

## 阶段三：音阶与调性

目标是从音程模式推导音阶，并用主音、调号、终止和持续语境判断中心。

1. [[06-基础乐理与指板/06-大调音阶|大调音阶]]与[[06-基础乐理与指板/07-调与调号|调与调号]]：推导C、G、D、F大调。
2. [[06-基础乐理与指板/12-小调音阶|小调音阶]]：比较自然、和声与古典语境的旋律小调。
3. [[06-基础乐理与指板/13-关系调同主音调与五度圈|关系调同主音调与五度圈]]：分开相同调号与相同主音。
4. [[06-基础乐理与指板/14-五声音阶|五声音阶]]：从七声音阶选择音级，并落实到实际音名与指板。
5. [[06-基础乐理与指板/15-调式入门|调式入门]]：比较同主音Dorian／Aeolian、Mixolydian／Ionian，避免“从某音开始就是某调式”。

阶段产出：能在非C调构造正确拼写的音阶，说明A自然／和声／旋律小调差异，并用多项证据而非首音判断调式。若调号和临时变化音混淆，回退“调与调号”；若共享音集合就误判同一中心，回退“关系调同主音调与五度圈”。

## 阶段四：和弦体系

目标是把和弦符号拆成组成音、实际低音、音区与吉他配置。

1. [[06-基础乐理与指板/08-三和弦构成|三和弦构成]]：用三度叠置推大、小、减、增三和弦。
2. [[06-基础乐理与指板/16-七和弦构成|七和弦构成]]：比较大七、属七、小七、半减七与减七。
3. [[06-基础乐理与指板/17-和弦转位与低音|和弦转位与低音]]：用实际最低音判断原位、转位与斜线和弦。
4. [[06-基础乐理与指板/18-挂留和弦与附加音和弦|挂留和弦与附加音和弦]]：区分sus2／sus4、add9与9。

阶段产出：看到C/E能写C E G并指出E为低音；看到C9能保留B♭，不把它缩成Cadd9。需要先从按法进入时，可到[[02-和弦系统/07-常用七和弦|常用七和弦]]核对实响，再回理论课解释。

## 阶段五：功能和声

目标是从“连续几个和弦”进入带调性、乐句与后续语境的分析。

1. [[06-基础乐理与指板/09-顺阶和弦与级数|顺阶和弦与级数]]、[[06-基础乐理与指板/19-和声功能|和声功能]]：建立调内材料与T／PD／D的语境。
2. [[06-基础乐理与指板/20-终止式与乐句|终止式与乐句]]：结合句末、低音、最高声部和节奏判断终止。
3. [[06-基础乐理与指板/21-小调和声|小调和声]]：理解自然v与升导音V／V7的差别。
4. [[06-基础乐理与指板/22-副属和弦|副属和弦]]：从目标反推V/x，不凭一个变化音下结论。
5. [[06-基础乐理与指板/23-调式借用|调式借用]]：从同主音材料解释iv、♭VI、♭VII，并与副属区分。
6. [[06-基础乐理与指板/24-转调入门|转调入门]]：比较短暂主音化、新中心维持、共同和弦与直接转调。

阶段产出：能解释C调D7→G为何是V7/V，Fm为何是借用iv，并从后续句法区分属和弦主音化与转到G大调。若只贴级数标签，回退“和声功能”；若V–I出现就自动叫完全正格，回退“终止式与乐句”。

## 阶段六：分析与编配

目标是把旋律、低音、内声部、功能、节奏和吉他可执行性放在一份记录中。

1. [[05-弹唱与伴奏/09-声部连接与和弦配置|声部连接与和弦配置]]：追踪共同音、级进与外声部，区分古典四部规则和吉他弹唱需要。
2. [[05-弹唱与伴奏/10-旋律配和弦与非和弦音|旋律配和弦与非和弦音]]：识别经过、邻、先现与挂留，并比较两套合理配法。
3. [[05-弹唱与伴奏/03-和弦级数与移调|和弦级数与移调]]：分开级数、按法、配置与实响。
4. [[05-弹唱与伴奏/11-乐句分析与编配实战|乐句分析与编配实战]]：完成G大调4/4、E小调6/8和A大调移调案例。
5. [[05-弹唱与伴奏/08-完整歌曲编配流程|完整歌曲编配流程]]：用纸面、实弹与回听三层证据形成迭代记录。

阶段产出：能为一段完整短句逐音写音区、起拍和时值，提出有依据的和弦与低音，完成移调并说明替代配置。完成后进入[[07-练习与复盘/07-中级乐理综合测验|中级乐理综合测验]]；若配和弦只能写“好听”，回退阶段五，若时值无法填满小节，回退阶段一。

## 完成标准

阶段一与二可并行；已有基础者可用综合测验的辨认题定位入口，但不能以猜对一道题跳过所有推导。完成一个阶段至少要能：独立完成推导题、用非C调或不同拍号迁移、说明一个易混边界、知道错误时回哪一课。

理论核对不等于实际演奏或听辨完成。涉及配置、音色、歌唱与节拍稳定的任务，仍需在自己的速度、乐器和身体状态下验证；出现疼痛、麻木或控制下降时停止，并回看[[08-保养安全与排错/01-疼痛疲劳与停止练习边界|停止练习边界]]。
