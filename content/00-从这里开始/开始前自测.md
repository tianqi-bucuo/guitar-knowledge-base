# 开始前自测

## 适用对象

任何准备开始本路线、重建基础或只想解决当前问题的读者，都可以用本页选择入口。本自测不计分，不是考试、等级认证、医疗筛查或诊断；“不确定”只是提示你从更早的说明页开始。

> 本页只提供一般性练习与安全信息，不用于诊断或治疗。出现疼痛、麻木或针刺感、无力、肿胀、动作控制下降或明显不适时，立即停止本项练习。症状持续、反复或加重，或已影响日常活动或握持能力时，请向合格医疗专业人士求助；严重疼痛、外伤后失去感觉或无法活动时，按所在地急诊指引及时就医。[^safety-bapam][^safety-nhs-rsi][^safety-nhs-finger]

## 导航方法

依次回答“是 / 否 / 不确定”，只记录可直接观察的现象，不把答案换算成总分。某一项出现上述症状时，立即退出该动作；这是一条安全分流，不是“低分”，也不要继续完成后续动作来证明自己。

没有症状但答案为“否”或“不确定”时，打开该项推荐页，从入门练习开始。多个入口都适合时，优先选择列表中较早的一项。

## 有序链接

1. 你能说出六根空弦的目标字母，并知道调音时不应盲目持续升高张力吗？“否 / 不确定”从 [[00-从这里开始/吉他调音与标准音|吉他调音与标准音]] 开始。
2. 坐下或站立时，琴体能由身体、座椅或背带稳定支撑，而不是主要靠双手夹住吗？“否 / 不确定”进入 [[01-持琴与基础动作/坐姿与站姿|坐姿与站姿]]。
3. 在一根弦的低把位按音时，你能逐步找到清晰发声所需的最低压力，而不是一味加力吗？“否 / 不确定”进入 [[01-持琴与基础动作/正确按弦|正确按弦]]。
4. 你能分别做出下拨、上拨，并在拨片不频繁滑动的情况下回到准备位置吗？“否 / 不确定”进入 [[01-持琴与基础动作/拨片握法与上下拨|拨片握法与上下拨]]。
5. 别人随机报出弦号时，你能看准目标弦再拨，并听见单独、可重复的声音吗？“否 / 不确定”进入 [[01-持琴与基础动作/空弦与单音练习|空弦与单音练习]]。
6. 任一动作若触发安全提示中的症状，停止该动作并寻求适当帮助；不要把它归入上述推荐，也不要以忍耐程度评分。

## 完成标准

你已选择一个没有触发症状、且与“否 / 不确定”答案对应的真实入口，并能解释选择依据。这里没有“及格”或“失败”：若触发安全分流，完成标准就是停止动作并采取适当求助，而不是继续测试。

## 更新策略

推荐只连接已经发布的页面；新增页面后再按可观察问题调整分流。所有安全措辞保持非诊断，不根据答案推断疾病，也不把症状改写成训练挑战。
