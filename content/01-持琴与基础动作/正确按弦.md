# 正确按弦

## 学习目标与先修知识

先完成 [[01-持琴与基础动作/左手拇指与手腕|左手拇指与手腕]]。本页完成后，你应能把指尖放在目标品丝后方，逐步增加到“刚好清晰”的最小有效压力，并根据闷音、杂音或误碰相邻弦的现象选择修正，而不是默认继续加力。

> 安全边界：本页不用于诊断或治疗。出现疼痛、麻木或针刺感、无力、肿胀、动作控制下降或明显不适时，立即停止；症状持续、反复或加重时，请向合格医疗专业人士求助。[^safety-bapam][^safety-nhs-finger]

## 核心概念

按弦点通常放在目标品丝后方、靠近品丝但不直接压在金属条上，这样更容易用较少压力得到清晰声音。[^fretting-fender] 压力不足可能使弦没有稳定接触品丝；但在声音已经清晰后继续挤压，并不会靠按弦手制造更大音量。[^fretting-fender][^dynamics-fender]

因此，本页的目标不是“最用力”，而是“最小有效压力”：从轻触开始，逐步增加，找到声音由闷或杂变为清晰的临界区域。指尖方向也要避免碰到本应自由振动的相邻弦。

杂音不一定都是学习者动作造成的。琴弦状态、弦距、品丝、琴颈或其他设置也可能参与问题。[^fretting-fender] 若同一位置在合理接触和压力下持续异常，不要靠死按解决，应请有经验的教师或维修人员检查。

## 图示与操作步骤

1. 选择一根中间弦和低把位。先辨认目标品丝：手指放在品丝朝琴头一侧的格内，并靠近品丝边缘。
2. 指尖只轻触琴弦，不加足压力；拨弦并记住此时的闷音或杂音，作为对照。
3. 每次只增加一点压力并重新拨弦。声音第一次稳定变清晰时停下，观察拇指、手腕和肩膀是否仍可放松。
4. 再多加一点压力作比较；如果声音没有变得更清晰，就退回刚才的位置，建立“刚好够用”的感觉。
5. 单独拨响相邻弦，确认按弦手指没有压住或碰停它们。若误碰，先改变指尖接触方向，再重新寻找最小压力。
6. 松开手指，让手恢复，再换另一根弦重复；不把同一手型强行搬到所有弦。

## 常见错误及修正

| 可观察现象               | 可能原因                             | 修正动作                                   |
| ------------------------ | ------------------------------------ | ------------------------------------------ |
| 声音闷、没有明确音头     | 压力尚不足或手指碰到别的弦           | 先核对目标弦，再逐步增加压力               |
| 有细碎杂音               | 离目标品丝太远、压力不稳，或器材因素 | 先移到品丝后方并稳定压力；持续异常再查器材 |
| 声音已清晰，手却越来越紧 | 把用力当成正确程度                   | 逐步减力，找到刚开始变差前的清晰位置       |
| 相邻空弦发不出来         | 指腹或其他手指误触                   | 调整指尖方向，逐根检查相邻弦               |
| 同一处总是异常           | 可能不只与手法有关                   | 换弦和换品位对照，仍持续则请人检查设置     |

## 分级练习

以下为本页原创练习。出现皮肤疼痛或其他安全提示症状时停止，不把忍痛视为“长茧训练”。

### 入门｜从轻触到清晰

在一根中间弦上，从无声轻触开始逐步加压。每次拨弦后用“闷 / 杂 / 清晰”记录结果；第一次稳定清晰后停止增加力量。

### 巩固｜刚好与过量对照

找到清晰音后，先刻意增加一点压力，再退回刚好清晰的位置。比较两者声音和手部紧张度，确认过量压力没有带来必要改善。

### 挑战｜跨弦排查

在粗、中、细三组弦上各选一个低把位单音。每次按响目标音，再逐根检查两侧相邻弦；若出现问题，明确归类为位置、压力、误碰或可能的器材因素。

## 自我检查标准

- 指尖位于目标品丝后方，而不是压在品丝顶上或远离品丝。
- 你能从轻触逐步找到清晰音，并在声音已稳定时停止加力。
- 目标音与相邻弦可以分别发声；出错时，你能指出是位置、压力还是误碰需要先调整。
- 同一位置持续异常时，你会停止死按并考虑器材检查，而不是把所有杂音归咎于手指。
