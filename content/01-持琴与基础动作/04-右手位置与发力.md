# 右手位置与发力

## 学习目标与先修知识

标题按常见的右手持琴方式命名：右手持琴者通常用右手拨弦；左手持琴者请镜像理解，把负责拨弦的手视为“拨弦手”。[^technique-fender] 先完成 [[01-持琴与基础动作/02-坐姿与站姿|坐姿与站姿]]，让琴体不依赖拨弦手压住才稳定。

本页目标是找到一个可重复的拨弦基准区，比较轻与中等触弦带来的音量变化，并让拨弦后能回到准备位置，而不把按弦手越捏越紧。

> 安全边界：本页不用于诊断或治疗。出现疼痛、麻木或针刺感、无力、肿胀、动作控制下降或明显不适时，立即停止；症状持续、反复或加重时，请向合格医疗专业人士求助。[^safety-bapam]

## 核心概念

拨弦或扫弦的力量会影响音量；想改变响度时，应主要调整拨弦手的触弦方式，而不是让按弦手同步加大挤压。[^dynamics-fender] 本页用“轻”和“中等”作对照，只比较自己同一把琴、同一根弦的可控差异，不把它们当成固定音量标准。

前臂可以在琴身边缘获得轻度接触，手腕、手掌或小指是否短暂接触琴面，则随手型与任务变化。悬空、锚定小指、固定手掌都不是本页强制规则，也没有某一个关节必须独自提供全部动力。

单音练习时，可以尝试让手指拨过琴弦后自然靠到相邻弦的 rest stroke，作为一种控制实验；它只是可选方法，不是所有拨弦任务的统一答案。[^posture-berklee]

## 图示与操作步骤

1. 让琴体由姿势支撑，拨弦侧前臂自然落在琴身边缘。检查肩膀没有为了够到琴弦而持续抬起。
2. 把手移到音孔附近作为基准区，先用裸指或尚未强调握法的轻触拨响一根中间空弦。
3. 拨弦后让手离开弦的路径，回到能再次拨同一根弦的位置；动作幅度以不频繁误碰相邻弦为准。
4. 用“轻”触弦拨一次，再用“中等”触弦拨一次。只改变拨弦侧，观察音量差别；若按弦手或肩膀同时收紧，重新降低力量。
5. 尝试一次自由拨过琴弦，再尝试一次可选 rest stroke。比较哪一种更容易命中目标弦，不急着固定选择。

## 常见错误及修正

| 可观察现象               | 可能原因                 | 修正动作                               |
| ------------------------ | ------------------------ | -------------------------------------- |
| 想弹响一点时全身一起绷紧 | 把音量变化理解成全身加力 | 回到轻触，只让拨弦侧逐步增加触弦力量   |
| 每次拨弦后手跑到很远     | 准备位置不明确或动作过大 | 缩小路径，让手能直接回到目标弦附近     |
| 误以为必须悬腕或必须锚定 | 把一种选择当成规则       | 比较两种状态，以稳定、可动和无症状为准 |
| 前臂压住琴身才觉得稳定   | 拨弦手替代了持琴支撑     | 返回姿势页，先让身体或背带承担支撑     |
| 声音变化时按弦手同步死夹 | 两手用力未分离           | 只用空弦做轻/中对照，暂时移除按弦任务  |

## 分级练习

以下为本页原创练习，不设置统一音量值或速度门槛。

### 入门｜单弦返回

选择一根中间空弦，轻拨后让手回到准备位置。每次先看准目标弦，再拨；若碰到相邻弦，就缩小动作而不是提高速度。

### 巩固｜轻与中等对照

在同一根空弦上交替做“轻、轻、中等、轻”。用录音或自己的听感核对中等触弦通常更响，同时检查肩膀和按弦手没有跟着加力。

### 挑战｜接触方式比较

分别尝试自由拨过和可选 rest stroke，记录目标弦命中、相邻弦误触和回位是否稳定。保留更适合当前单音任务的做法，同时知道换任务后可以重新选择。

## 自我检查标准

- 你能说明标题的左右手假设，并把“拨弦手”角色正确镜像到自己的持琴方式。
- 连续拨同一根弦时，手能回到相近准备位置，琴体不会因拨弦侧离开而明显滑动。
- 轻与中等触弦产生可辨别的音量差异，而按弦手、肩颈没有同步明显夹紧。
- 你能解释悬空、锚定或 rest stroke 都是可选择实验，不是唯一正确动作。
