# 旋律配和弦与非和弦音

## 学习目标与先修知识

请先完成 [[06-基础乐理与指板/18-和声功能|和声功能]] 与 [[05-弹唱与伴奏/09-声部连接与和弦配置|声部连接]]。本页不教你为每个音硬配一个和弦，而是先找乐句骨干，再判断某个音在当下和弦中是和弦音、经过音、邻音、先现音还是挂留音。

完成后，你应能为同一旋律提出至少两种合理配法，并用音集合、低音、和声节奏与乐句方向解释差异。配法不是凭喜好命名：和弦音必须能核对，非和弦音必须能说明从哪来、往哪去。

## 核心概念

### 先分旋律骨干与装饰

在4/4拍中，重拍上的长音常比弱拍短音更能限制和弦选择，但“重拍音一定是和弦音”并非绝对规则。经过音可以落在重拍而成为重音经过音；判断仍需看它是否以级进连接前后较稳定的音。[^nct-intro][^passing]

分析顺序可固定为：

1. 写清调、拍号、音区、起拍和时值；
2. 圈出长音、重拍音与乐句终点；
3. 为每个位置列出包含骨干音的候选和弦；
4. 检查低音与功能方向，而非只看“含不含这个音”；
5. 对不在和弦集合中的音说明接近与离开方式；
6. 最后才比较手型、音色和伴奏密度。

### 四类常见非和弦音

| 类型   | 4/4原创微型例                                             | 判定依据                                |
| ------ | --------------------------------------------------------- | --------------------------------------- |
| 经过音 | C和弦上C4（第1拍）–D4（第2拍）–E4（第3拍）                | D不是C和弦音，以同方向级进连接C与E      |
| 邻音   | C和弦上E4（第1拍）–F4（第2拍）–E4（第3拍）                | F离开E一步又反向回到E                   |
| 先现音 | G7末尾B3（第3拍）–C4（第4拍），下一小节C和弦继续C4        | C在和声改变前提前出现，随后成为新和弦音 |
| 挂留音 | F和弦第4拍保持F4，跨到C和弦第1拍仍为F4，再在第2拍下行至E4 | F先准备、再延留成不协和、最后级进解决   |

先现音必须指向紧接的下一个和弦；挂留必须有准备、延留与解决三阶段。只有“听起来悬”或“出现了F”都不足以命名。[^anticipation][^suspension] 连续两个经过音也是可能的；名称描述线条行为，不限制只能有一个装饰音。[^passing]

## 图示与操作步骤

### 固定旋律

以下是本站原创C大调四小节旋律，每个音为四分音符，第四小节C4为全音符：

| 小节 | 旋律事件                    | 骨干观察                            |
| ---- | --------------------------- | ----------------------------------- |
| 1    | C4@0:1 E4@1:1 G4@2:1 E4@3:1 | C、E、G完整呈现主和弦材料           |
| 2    | A4@0:1 G4@1:1 A4@2:1 C5@3:1 | A与C稳定，G可作A的下邻音            |
| 3    | F4@0:1 E4@1:1 D4@2:1 B3@3:1 | F向D级进，E可视作经过；B指向末小节C |
| 4    | C4@0:4                      | 长时值终止音C限制终点功能           |

### 配法甲核对

此表采用“一小节一个和弦”的较慢和声节奏。音集合只写音类，低音另写实际音区。

| 小节 | 起拍 | 时值 | 和弦 | 和弦音集合 | 低音 |
| ---- | ---- | ---- | ---- | ---------- | ---- |
| 1    | 0    | 4    | C    | C E G      | C3   |
| 2    | 0    | 4    | Am   | A C E      | A2   |
| 3    | 0    | 4    | G7   | G B D F    | G2   |
| 4    | 0    | 4    | C    | C E G      | C3   |

分析为I–vi–V7–I。第二小节G4不是Am和弦音，但位于A4–G4–A4的弱拍邻接运动；第三小节F、D、B都是G7和弦音，E是F到D之间的经过音。最后B3→C4同时呈现导音解决，V7→I形成清楚收束。

### 配法乙核对

第二种配法让前两小节具有下属色彩，并在第三小节把和声节奏加快。

| 小节 | 起拍 | 时值 | 和弦 | 和弦音集合 | 低音 |
| ---- | ---- | ---- | ---- | ---------- | ---- |
| 1    | 0    | 4    | Am7  | A C E G    | A2   |
| 2    | 0    | 4    | F    | F A C      | F2   |
| 3    | 0    | 2    | Dm7  | D F A C    | D3   |
| 3    | 2    | 2    | G7   | G B D F    | G2   |
| 4    | 0    | 4    | C    | C E G      | C3   |

第一小节旋律四音都属于Am7，但整句最终仍在C结束，因此这里只把vi7理解为主功能区域的替代起点，不宣称已经转到A小调。第二小节A、C是F和弦音，G仍可作A的下邻音。第三小节前半以Dm7承接F4，E4是F4到D4的经过音；后半转G7后，D4、B3成为和弦音，于是形成ii7–V7–I。与配法甲相比，它用更快的和声节奏强化终止准备。

两种方案都不是“唯一答案”。甲的功能方向直接、适合初次排练；乙在第三小节制造更强推进，但换和弦更密。若旋律、速度或歌唱需要留白，较少和弦反而可能更合适。

### 自己配和弦的工作表

先复制固定旋律，不改变任何音；为每小节写“候选和弦、支持的骨干音、暂不属于和弦的音、该音的线性解释、低音、功能”。若解释只能写“听起来可以”，就退回实际音集合与前后音关系。纸面成立后再试弹；没有实际弹奏与听辨，不能断言音色平衡或手型衔接舒服。

## 常见错误及修正

- **旋律每换一个音就换和弦：** 先保持一小节一个和弦，确认哪些只是线性装饰。
- **和弦包含旋律音就算合理：** 还须检查低音、前后功能、和声节奏与终止方向。
- **把所有调外音都叫经过音：** 经过音要以级进同向连接；邻音要离开后返回。
- **把未准备的强拍音叫挂留：** 补查前一和弦是否已有同音、是否保持、是否级进解决。
- **方案越复杂越高级：** 复杂度只有在段落功能和可执行性需要时才有价值。

## 分级练习

### 一级：辨认

R1. 在固定旋律与配法甲中，指出第二小节G4和第三小节E4的类别，并写出其前后音。

### 二级：推导

D1. 不看核对表，从固定旋律推导配法乙的和弦、和弦音集合、低音与每次换和弦的时值，再解释第三小节为何允许一小节两个和弦。

### 三级：应用

A1. 为同一旋律提出第三种配法。至少保留最终C和弦；逐项标出和弦音与非和弦音，并比较它和甲、乙在功能、和声节奏与吉他换形上的取舍。

### 答案与解析

- R1：第二小节G4位于A4–G4–A4之间，是下邻音；第三小节E4位于F4–E4–D4之间，是下行经过音。类别来自接近和离开方式，不来自所在小节编号。
- D1：Am7（4拍，A C E G，低音A2）–F（4拍，F A C，低音F2）–Dm7（2拍，D F A C，低音D3）/G7（2拍，G B D F，低音G2）–C（4拍，C E G，低音C3）。第三小节旋律前半F支持Dm7，后半D、B支持G7，二拍一次换和弦形成ii7–V7推进。
- A1：答案不唯一。最低要求是每个和弦音集合与低音可核对、每小节合计4拍、每个非和弦音有前后运动依据，并说明为何该功能方向服务终点。纸面答案不能替代实弹后的音色、换形与歌唱复核。

## 自我检查标准

你能从实际音集合证明和弦是否包含骨干音；能区分经过、邻、先现与挂留；能让每小节和声时值合计4拍；能对两种配法说出音乐取舍，而不是把其中一种称作标准答案。
