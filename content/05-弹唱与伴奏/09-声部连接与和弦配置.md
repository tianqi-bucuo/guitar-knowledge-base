# 声部连接与和弦配置

## 学习目标与先修知识

先会 [[06-基础乐理与指板/16-和弦转位与低音|转位低音]] 和 [[06-基础乐理与指板/18-和声功能|功能]]。本页从“整块换形”前进一步：把每个实际音追踪到下一个和弦，解释选择某种配置的理由。目标不是立刻完成古典四部写作，而是能识别自己的低音、最高声部与中间线条。

## 核心概念

### 配置回答怎么摆，连接回答怎么走

同一个C和弦可写C3 E3 G3，也可写C3 G3 E4；根与性质相同，排列及音区不同。声部连接追踪C3去哪、E3去哪、G3去哪，关心独立线条与可唱性，不只关心下一块和弦是否按对。[^leading]

共同音若在相同音区保留，可减少移动；没有共同音时，可尝试级进或较短移动。但“每条都尽量近”不是唯一标准：最高旋律有优先级，低音需表达根音或指定转位，不能为了省手指把必要音删掉。适当跳进可作为旋律设计，需说明目的。

### 两条线的运动类型

| 类型       | 两声部变化（低／高） | 检查方式                 |
| ---------- | -------------------- | ------------------------ |
| 反向       | C3／C4→D3／B3        | 一条上行、一条下行       |
| 斜向       | C3／E4→C3／F4        | 一条保持、一条移动       |
| 同向非平行 | C3／E4→D3／G4        | 同方向，移动音程不同     |
| 平行       | C4／E4→D4／F♯4       | 两条同上全音，保持大三度 |

平行是同向的特例。[^motion] 这里描述事实，不自动判好坏。古典独立声部训练通常约束连续平行纯五度／八度；吉他扫弦、强力和弦或某些风格中的平行运动可以是主动选择。[^parallels] 不把四部和声作业的评分规则套成所有弹唱禁令；若任务明确要求SATB，则须另查音域、重复、声部交叉等完整规则。

## 图示与操作步骤

### 吉他配置核对

标准定弦，无变调夹；x不发声，tuple按6→1弦，实响按发声弦序。上方三弦形不代表完整乐队最低音。

| 配置    | 六到一弦    | 实响音高          |
| ------- | ----------- | ----------------- |
| C开放   | x-3-2-0-1-0 | C3 E3 G3 C4 E4    |
| Am开放  | x-0-2-2-1-0 | A2 E3 A3 C4 E4    |
| G/B开放 | x-2-0-0-0-3 | B2 D3 G3 B3 G4    |
| G7开放  | 3-2-0-0-0-1 | G2 B2 D3 G3 B3 F4 |
| C高三弦 | x-x-x-5-5-3 | C4 E4 G4          |
| F高三弦 | x-x-x-5-6-5 | C4 F4 A4          |
| G高三弦 | x-x-x-4-3-3 | B3 D4 G4          |

### 逐声部比较C→Am

C开放到Am开放，4弦E3、2弦C4、1弦E4保持，3弦G3→A3上行全音，5弦C3→A2下行小三度。指位保持与实际共同音保持在这里一致；若换把或跨弦，同一音也可能由另一手指负责，不能只看手指有没有动。

这组例子有五个发声音，并非严格SATB；同一音类可以在两个音区重复。记录可以按弦追踪，但长线条若转交到另一根弦，还须跟声音走，不能把弦号永远当作独立旋律身份。

### 高三弦C→F→G→C

按表顺序，三条线为C4→C4→B3→C4，E4→F4→D4→E4，G4→A4→G4→G4。第一步有共同C，另外两音各上行；F→G中C→B半音、F→D小三度、A→G全音；最后B→C、D→E，G保持。每步仍包含对应三和弦三音类，不能为“全部一步内移动”而误写F→E造成错误和弦。

纸面另加低音C3 F2 G2 C3，可形成原位根音线；若只有高三弦，F形最低C4，是F/C，G形最低B3，是G/B。局部配置与整体低音需分层标注。先慢速分声部弹，再合成；没有实际试弹时只能确认音位，不能认定转换舒适。

### 实际选择顺序

先固定旋律→确定低音→补必要三、七音→再安排五音和重复→逐声部检查跨度、重音与可弹性。G7到C时B→C、F→E是有意义的趋向，但不同配置可以把这些音放在不同弦或音区；不要要求每一个开放形机械执行某套四部连接。

## 常见错误及修正

- 只写和弦名不写八度：无法验证谁跳了多远，也无法判最低音。
- 共同音必须同一手指：声音可以跨弦交接，先核实实际音高。
- 把最近配置当唯一正确：旋律、低音、风格与手部条件都可能优先。
- 在纸上说顶音C4，实际一弦E4仍响：调整配弦或明确旋律不是最高声部。

## 分级练习

### 一级：辨认

R1. C开放到Am开放哪些音区保持？高三弦F配置独奏时是F原位吗？如果贝斯另弹F2呢？

### 二级：推导

D1. 把高三弦C–F–G–C的三条音高线全部提高全音，写新和弦名与实响，不急着找新手型。

### 三级：应用

A1. 比较C4 E4 G4→C4 F4 A4，与C4 E4 G4→F4 A4 C5两种C→F配置。逐音量移动距离，说明为什么第一种更省移动，但第二种仍可能因旋律目标而被采用。

### 答案与解析

- R1：E3、C4、E4保持；高三弦F最低C4是F/C。若整体低音F2，整体可为F原位，不能忽略贝斯。
- D1：和弦D–G–A–D；三线D4→D4→C♯4→D4，F♯4→G4→E4→F♯4，A4→B4→A4→A4。每音升2半音，原半音连接仍保留，不将C♯写D♭破坏A三和弦拼写。
- A1：第一种按低中高匹配移动0、1、2半音，总3；第二种5、5、5半音，总15。前者保持共同C，后者把最高音推到C5，若旋律正需要C5就有理由采用。评价看音组成、实际音区与理由一致；手指舒适度需实际验证，不能仅用距离总和代替。

## 自我检查标准

能把至少三条线逐音写出，找共同音与半音趋向；能区分局部最低与整体最低。手腕或手指疼痛、麻木、控制下降时停止，见 [[08-保养安全与排错/01-疼痛疲劳与停止练习边界|停止练习边界]]。转位错误回 [[06-基础乐理与指板/16-和弦转位与低音|转位]]。
