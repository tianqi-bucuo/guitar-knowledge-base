# 调与调号

## 学习目标与先修知识

请先完成 [[06-基础乐理与指板/大调音阶|大调音阶]] 与 [[05-弹唱与伴奏/和弦级数与移调|和弦级数与移调]]。本页把实践中的“换调”拆成主音中心、调内音集合和书写记号，完成后你应能准确写出 C、G、D、F 四个大调及其调号。

## 核心概念

本页把“调”限定为以某个主音为中心、使用相应大调音集合的语境；调号是在谱首记录反复升降音的书写简记。[^key-signatures-puget] 两者相关却不是同一个概念，调号不能代替主音与实际音乐语境。

相对大小调可以共享调号，所以只看调号不能总是唯一确定调性；小调不在本页展开。[^solfege-libretexts] C 大调调号没有升降音，意思是它的调号内容为“无”，不是没有调号概念。

临时记号写在具体音符附近，改变局部音高或拼写；它不同于谱首的调号。[^accidentals-puget] 同样，变调夹品位也不是调名：必须结合手上按法与升高距离，另算实响调或实响和弦。

## 图示与操作步骤

下表是本站原创核对表，音阶拼写与调号内容必须逐字母对应。

| 大调   | 音阶拼写        | 调号升降音 |
| ------ | --------------- | ---------- |
| C 大调 | C D E F G A B   | 无         |
| G 大调 | G A B C D E F♯  | F♯         |
| D 大调 | D E F♯ G A B C♯ | F♯、C♯     |
| F 大调 | F G A B♭ C D E  | B♭         |

构造时先写七个依次出现的字母，再套大调全半音公式，最后把全曲反复需要的升降音收进调号列。对照变调夹时另写“按法”和“实响”，不要拿夹位替代调名。

## 常见错误及修正

- 把“无升降号”说成“没有调号概念”：准确写成 C 大调调号内容为无。
- 把一次临时升号当整个调号：确认它出现在谱首还是具体音符旁。
- 把夹二品直接叫 D 调：同时记录按法、升高距离与实响结果。
- 看到相同调号就断言唯一调性：补上主音中心与上下文证据。

## 分级练习

以下是本站原创练习，判断依据必须能在表中复核。

### 第一级：辨认

从表中说出 C、G、D、F 各自固定的升降音，并把临时记号与调号分成两类；混淆位置就重新定义。

### 第二级：映射

用大调公式重建 G 或 F 音阶，核对每个字母依次出现一次，再把固定升降音写入调号。拼写重复字母时退回第一级。

### 第三级：整合

回看上游移调例，同时写“按法名称”和“实响和弦/调”，说明 capo 品位本身不是调名。若只写夹位就退回第二级补齐推导。

## 自我检查标准

- 我能分别定义调、调号和临时记号，而不把三者互换。
- 我能准确写出 C/G/D/F 四行音阶与调号内容。
- 我能解释为什么相同调号不总能唯一确定调性。
- 我不会把变调夹品位直接当作调名。
