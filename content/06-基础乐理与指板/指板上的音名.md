# 指板上的音名

## 学习目标与先修知识

请先完成 [[06-基础乐理与指板/音高音名与唱名|音高音名与唱名]]，并用 [[00-从这里开始/吉他调音与标准音|吉他调音与标准音]] 核对空弦。本页从原有零到五品自然音继续推至十二品，目标是能独立解释“为什么这里是这个音”，同时保留实际音区。

> 安全边界：本页只提供一般性乐理与吉他练习信息，不用于诊断或治疗。弹奏出现疼痛、麻木或针刺感、无力、肿胀、动作控制下降或明显不适时立即停止；症状持续、反复或加重时，请向合格医疗专业人士求助。[^safety-bapam]

## 核心概念

标准定弦低到高，也就是六弦到一弦，为 `E A D G B E`。[^fretboard-yamaha] 在同一根弦上，向琴身方向移动一品，音高升高一个半音；这个方向规则只描述标准上弦枕后的正常品位。[^circle-yamaha]

自然音字母按 A 到 G 循环，其中 E–F、B–C 之间是半音，其余相邻自然音字母之间是全音。[^steps-puget] 所以 E 空弦后一品就是 F，而 F 到 G 需要再走两品。

本页表格只列自然音。未列出的品位仍然有声音，通常需要用升号或降号命名；例如六弦二品可写作 F♯ 或 G♭。同一音名也能出现在不同弦与品位，位置相同与音名相同不是一回事。

图中是位置集合，不规定弹奏路线或指法顺序；省略升降音也不表示空白位置没有声音。核心事实同时列在本站原创表中：

|  弦 | 0–5 品自然音位置 |
| --: | ---------------- |
|   6 | E0、F1、G3、A5   |
|   5 | A0、B2、C3、D5   |
|   4 | D0、E2、F3、G5   |
|   3 | G0、A2、B4、C5   |
|   2 | B0、C1、D3、E5   |
|   1 | E0、F1、G3、A5   |

推导时先写空弦字母，再判断下一个自然音距它半音还是全音；半音移动一品，全音移动两品。每走一步都同时报弦号、品号和音名。

上表的 `E0、F1` 中数字是**品号**，不是 E0/F1 的科学音区；下面改为“品号:实响音高”格式，防止混读。零品就是空弦。

### 从空弦推到十二品

以6弦为例：E2→1品F2→3品G2→5品A2→7品B2→8品C3→10品D3→12品E3。每一步按自然音间距加1或2品，累计12个半音便到高八度同名音。每弦12品都比自己的空弦高一个八度，不代表六根12品都同音。

| 弦  | 0–12品自然音（品号:实响）                        |
| --- | ------------------------------------------------ |
| 6   | 0:E2、1:F2、3:G2、5:A2、7:B2、8:C3、10:D3、12:E3 |
| 5   | 0:A2、2:B2、3:C3、5:D3、7:E3、8:F3、10:G3、12:A3 |
| 4   | 0:D3、2:E3、3:F3、5:G3、7:A3、9:B3、10:C4、12:D4 |
| 3   | 0:G3、2:A3、4:B3、5:C4、7:D4、9:E4、10:F4、12:G4 |
| 2   | 0:B3、1:C4、3:D4、5:E4、6:F4、8:G4、10:A4、12:B4 |
| 1   | 0:E4、1:F4、3:G4、5:A4、7:B4、8:C5、10:D5、12:E5 |

### 跨弦不能只搬同一个形状

6→5、5→4、4→3、2→1的空弦差五个半音；唯独3→2差四个半音。所以3弦4品与2弦空弦同为B3，若机械照抄“五品对下一空弦”，3弦5品会得到C4，比B3高半音。知道例外来自定弦关系，比背“这儿形状特殊”更可靠。

同音与八度要分开验证：6弦12品E3与4弦2品E3是同音异位；6弦空弦E2与6弦12品E3则是八度关系。用调音器时既看字母又看音区（若设备不显示音区，不能仅凭相同字母断言同音）。

### 同音与八度核对

| 位置甲  | 位置乙  | 实响  | 关系 |
| ------- | ------- | ----- | ---- |
| 3弦4品  | 2弦0品  | B3    | 同音 |
| 3弦5品  | 2弦1品  | C4    | 同音 |
| 6弦12品 | 4弦2品  | E3    | 同音 |
| 6弦0品  | 6弦12品 | E2→E3 | 八度 |

八度定位也能从空弦距离推导：6弦3品G2→4弦5品G3，是跨两弦加两品；4弦2品E3→2弦5品E4，则跨过3/2弦边界，要加三品。都先核对实际音名和音区，形状只是结果。

## 常见错误及修正

- 把品格编号当手指编号：本页数字只描述弦号和品号，不指定手指。
- 把第一弦当最低音弦：先按六弦到一弦说 `E A D G B E`。
- 见空白品位就说“没有音”：改说“表中省略了升降音”，再给出六弦二品的例子。
- 只背图不推导：遮住图，从空弦和全半音关系重新走到目标品。

## 分级练习

以下是本站原创练习，正确性由音名与品位对应关系判断。

### 一级：辨认

R1. 3弦4品与2弦空弦是同音还是八度？6弦12品与1弦空弦呢？都写音区。

### 二级：推导

D1. 从4弦D3出发，逐个自然音推到10品。再解释为什么4弦2品的高八度在2弦5品，而不是4品。

### 三级：应用

A1. 将旋律 B3 C4 D4 分别写在同一条3弦和同一条2弦上。慢速交替两条路线，解释音高相同但演奏感觉可能不同的原因；不要求两种音色完全一致。

### 答案与解析

- R1：前一组都是B3，同音异位。后一组为E3与E4，相差一个八度；两位置都叫E不够判为同音。
- D1：0:D3、2:E3、3:F3、5:G3、7:A3、9:B3、10:C4。2弦4品是D♯4，5品才是E4；跨两弦时这对空弦相差9半音，所以还需多3品达到12半音。
- A1：3弦为4、5、7品；2弦为0、1、3品。两组实际音高均为B3/C4/D4；弦粗、振动长度、空弦与按弦条件不同，音色和换把感觉可能不同。验收先核对音高与顺序，动作不适就停，不把音色差当成必然错音。

## 自我检查标准

- 我能从每根空弦推导零到五品自然音，不只照图背答案。
- 我能准确说出二弦一品是 C，而不是把 `1` 当手指号。
- 我能说明六弦二品虽未列仍有 F♯/G♭ 音高。
- 我不会把第一弦说成最低音弦，也不会把位置不同误作音名不同。
