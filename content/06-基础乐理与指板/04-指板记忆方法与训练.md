# 指板记忆方法与训练

## 学习目标与先修知识

请先完成 [[06-基础乐理与指板/02-指板上的音名|指板上的音名]] 与 [[06-基础乐理与指板/03-全音与半音|全音与半音]]。前两页解决“音名怎样推导”；本页解决“怎样把推导逐步变成可以直接调用的位置知识”。完成后，你应能在零到十二品内进行“位置→音名”和“音名→多个位置”两种检索，并把结果用于根音、和弦与音阶定位。

> 安全边界：本页只提供一般性乐理与吉他练习信息，不用于诊断或治疗。弹奏出现疼痛、麻木或针刺感、无力、肿胀、动作控制下降或明显不适时立即停止；症状持续、反复或加重时，请向合格医疗专业人士求助。[^safety-bapam]

## 核心概念

记住指板不等于一次背下所有弦品组合。标准定弦从六弦到一弦是 `E A D G B E`，同弦向琴身移动一品升高半音，十二品回到高八度同名音。[^fretboard-yamaha][^steps-puget] 这些规则使指板可以分层学习，而不是把每个位置当成互不相关的答案。

真正有用的记忆必须支持两个方向：看到“4弦7品”能说出A，听到或读到“A”也能在指定区域找到多个A。只会从空弦逐品数到目标，说明推导规则已经掌握，但位置尚未形成直接提取；只会背一张图，却不能解释邻近音或八度关系，也不够可靠。

本课把位置知识分成三层：

1. **锚点**：先掌握六弦、五弦的自然音位置。多数移动和弦和根音搜索会直接使用这两根低音弦。
2. **关系**：用八度位置把已知音迁移到四、三、二、一弦，同时明确二、三弦定弦边界造成的偏移。
3. **检索**：打乱题目顺序，交替练“位置→音名”和“音名→位置”，不依赖固定背诵路线。

这里不把 CAGED 当作记忆指板的替代品。CAGED 可以组织和弦形状，但如果不知道形状中的根音在哪里，仍然无法独立命名或移调；本页先建立音名与根音定位，再讨论形状系统会更稳妥。

## 图示与操作步骤

### 第一步：建立六弦与五弦锚点

先遮住答案，从空弦和自然音间距重新写出下表；核对正确后，再把它当作提取表。E–F、B–C 相邻一品，其余相邻自然音相隔两品。

| 弦  | 0–12品自然音锚点                         |
| --- | ---------------------------------------- |
| 6弦 | 0:E、1:F、3:G、5:A、7:B、8:C、10:D、12:E |
| 5弦 | 0:A、2:B、3:C、5:D、7:E、8:F、10:G、12:A |

第一弦与第六弦在相同品位使用相同字母名称，但实际音区相差两个八度，不能因此说成同一具体音高。十二品与空弦同名，但高一个八度。

锚点训练不要总从0品顺读到12品。可以把弦号与品号写成卡片，打乱后逐张回答；答错时回到最近的已知锚点和全半音关系，核对后将原题放回混合题目，而不是立刻连续重复同一个答案。

### 第二步：用八度关系迁移

下表描述零到十二品范围内常用的同名高八度位置。`x` 是起点品号；超过十二品时，这条路线暂不用于本课范围。

| 起点弦 | 高八度目标弦 | 品位变化 | 示例                 |
| ------ | ------------ | -------- | -------------------- |
| 6弦x品 | 4弦x+2品     | +2       | 6弦3品G2 → 4弦5品G3  |
| 5弦x品 | 3弦x+2品     | +2       | 5弦3品C3 → 3弦5品C4  |
| 4弦x品 | 2弦x+3品     | +3       | 4弦5品G3 → 2弦8品G4  |
| 3弦x品 | 1弦x+3品     | +3       | 3弦7品D4 → 1弦10品D5 |

前两种形状加两品，后两种加三品，因为跨过了3弦G到2弦B的四半音定弦关系。形状是由音高关系得到的结果，不是独立真理；换调弦后必须重新核对。

### 第三步：补齐升降音

自然音稳定后，再从相邻锚点定位升降音。例如6弦3品是G，则4品在当前十二平均律位置可按语境写G♯或A♭；5弦7品是E，6品可写E♭或D♯。[^enharmonic-puget] 先说位置，再根据调、音阶或和弦关系选择拼写，不把“同一品位”误解成“任何语境都可随意换名字”。

### 第四步：做双向混合检索

使用下面的记录方式，每题只标一种结果，不用“差不多会”代替证据：

| 结果       | 判定                                 | 下一步                         |
| ---------- | ------------------------------------ | ------------------------------ |
| 直接提取   | 不按固定路线逐品数，答案与核对表一致 | 保留在混合题中                 |
| 推导正确   | 借助锚点、半音或八度关系得到正确答案 | 下次继续混入，目标是缩短推导链 |
| 错误或漏位 | 音名、弦品、方向或拼写不正确         | 写出推导过程并回到对应锚点     |

第一类题给出弦号与品号，回答音名；第二类题给出音名和范围，列出所有位置。只有两类题在重新打乱后都能稳定完成，才扩大到新弦、升降音或更高把位。ABRSM 的练习资源强调先说明目的、做法、结果与下一步；这里据此使用可复核结果，而不以练习时长替代掌握证据。[^practice-abrsm]

### 第五步：进入音乐应用

- **和弦根音**：给出G、C、D、A等和弦符号，先在六弦或五弦找到根音，再说明移动形状为什么得到该和弦名。
- **音阶定位**：给出一个调的音集合，在限定把位标出主音，并从主音推其他音级；不要只背一个框形。
- **旋律换位置**：把同一组三个音放在不同弦组，核对音区是否相同，再比较换弦与把位选择。
- **排错**：答案与图不一致时，回查标准定弦、目标弦、品号、二三弦边界和升降音拼写，逐项排除。

## 常见错误及修正

- 一开始硬背整张全指板：先建立六、五弦自然音锚点，再用八度关系扩展；升降音最后加入。
- 永远按0品到12品顺读：打乱弦品顺序，并加入“音名→全部位置”的反向题。
- 把八度形状处处都当加两品：跨过二、三弦边界的路线改为加三品，并用实际音名复核。
- 只找到一个目标音就停止：题目要求“全部位置”时，逐弦检查零到十二品，不用最熟悉的位置代替完整答案。
- 把G♯与A♭理解成永远可以互换：位置核对后，仍按当前调性、音程或和弦语境选择拼写。
- 只背CAGED形状而不标根音：先在六、五弦说出根音，再把形状名称与该根音连接。

## 分级练习

以下为本站原创练习。先独立作答，再用 [[06-基础乐理与指板/02-指板上的音名|指板上的音名]] 的十二品表或调音器核对；调音器只显示字母时，仍要自行确认八度与位置关系。

### 一级：辨认

R1. 不从空弦逐品朗读，写出以下位置的音名与实际音区：6弦7品、5弦8品、4弦10品、3弦9品、2弦6品、1弦3品。标出哪些答案可由六、五弦锚点直接得到。

### 二级：推导

D1. 分别从5弦3品、4弦5品、3弦7品出发，用本页八度关系找到高八度同名音。说明为什么第一组加两品，而后两组加三品。

### 三级：应用

A1. 在标准定弦零到十二品内，逐弦找出所有G。然后说明：若以六弦根音的可移动大和弦形状为例，根音落在六弦3品时为什么和弦名是G，而把同一相对形状移到六弦5品后为什么应改名为A。

### 答案与解析

- R1. 依次为B2、F3、C4、E4、F4、G4。六弦7品B与五弦8品F属于第一层锚点；其他位置可由单弦推导或八度关系核对。只写字母不写音区，不能证明已区分同名的不同八度。
- D1. 5弦3品C3→3弦5品C4；4弦5品G3→2弦8品G4；3弦7品D4→1弦10品D5。5→3弦没有跨越G–B定弦边界，所以目标加两品；4→2与3→1都跨过该边界，所以目标加三品。
- A1. G位于6弦3品、5弦10品、4弦5品、3弦0品与12品、2弦8品、1弦3品。移动形状的和弦名随其根音改变：六弦3品是G，六弦5品是A；形状相对间距可以相同，绝对根音与和弦名不能保持不变。

## 自我检查标准

- 我能打乱顺序说出六弦与五弦零到十二品的自然音，不依赖从空弦顺读。
- 我能解释四种八度路线，并指出跨二、三弦边界时为什么多一品。
- 给定一个自然音，我能逐弦检查并列出零到十二品内的所有位置。
- 给定一个弦品位置，我能说出音名；需要推导时，能写出使用了哪个锚点或关系。
- 我能把六、五弦根音用于移动和弦命名，而不是只记形状名称。
- 我能区分“同一品位的等音拼写”和“当前语境应使用的音名”。
