# 顺阶和弦与级数

## 学习目标与先修知识

请先完成 [[06-基础乐理与指板/07-三和弦构成|三和弦构成]] 与 [[06-基础乐理与指板/06-调与调号|调与调号]]。本页不以弹唱移调技术为先修：从音阶逐级构造，再把C、G、D等调中的具体和弦翻译成可迁移的关系。

> 安全边界：本页只提供一般性乐理与吉他练习信息，不用于诊断或治疗。弹奏出现疼痛、麻木或针刺感、无力、肿胀、动作控制下降或明显不适时立即停止；症状持续、反复或加重时，请向合格医疗专业人士求助。[^safety-bapam]

## 核心概念

从大调的每个音级出发，只用调内音并隔一个音叠置出三和弦，就得到七个大调顺阶三和弦；质量模式为大–小–小–大–大–小–减。[^diatonic-puget]

罗马数字写作 I–ii–iii–IV–V–vi–vii°：大写表示大三和弦，小写表示小三和弦，小写加 `°` 表示减三和弦。[^roman-puget] 大小写和符号都是结构信息，不是排版风格。

级数保存跨调关系，却不会自动决定节奏、旋律、音色或情绪。移到别的调时，具体和弦名会改变，但每个位置的级数关系可以保留并重新实现。

## 图示与操作步骤

下表是本站原创的 C 大调顺阶三和弦核对表。

| 级数 | 音名构成 | 质量     | C 大调和弦 |
| ---- | -------- | -------- | ---------- |
| I    | C–E–G    | 大三和弦 | C          |
| ii   | D–F–A    | 小三和弦 | Dm         |
| iii  | E–G–B    | 小三和弦 | Em         |
| IV   | F–A–C    | 大三和弦 | F          |
| V    | G–B–D    | 大三和弦 | G          |
| vi   | A–C–E    | 小三和弦 | Am         |
| vii° | B–D–F    | 减三和弦 | Bdim       |

构造时从目标音级开始，在 `C D E F G A B` 中隔一个音取三项，回到表首时循环；随后用三和弦公式判质量，最后才写罗马数字。

两个仓库已有原创进行可直接反查：`C–G–Am–Em = I–V–vi–iii`，对应 [[02-和弦系统/09-C-G-Am-Em和弦进行|C-G-Am-Em和弦进行]]；`C–Am–F–G = I–vi–IV–V`，对应 [[02-和弦系统/10-C-Am-F-G和弦进行|C-Am-F-G和弦进行]]。

### 换成G调，不能照抄C调字母

先写G A B C D E F♯；在第二级A上取A C E，三音C距A3半音、E距A7半音，故Am而非A大三。第七级F♯取F♯ A C，距离0/3/6，故F♯dim。调号中的F♯也出现在Bm与D的组成里；不是只给“以F开头的和弦”加升号。

### 大调级数核对

| 级数 | G调组成 | 和弦名 |
| ---- | ------- | ------ |
| I    | G B D   | G      |
| ii   | A C E   | Am     |
| iii  | B D F♯  | Bm     |
| IV   | C E G   | C      |
| V    | D F♯ A  | D      |
| vi   | E G B   | Em     |
| vii° | F♯ A C  | F♯dim  |

### 从进行到吉他，再回到分析

C–Am–F–G在G调对应G–Em–C–D，保留I–vi–IV–V。标准吉他可用G `3-2-0-0-0-3`、Em `0-2-2-0-0-0`、C `x-3-2-0-1-0`、D `x-x-0-2-3-2`；实响低音依次G2 E2 C3 D3，不是把每一个原低音都简单提高同一音程，因为这里重新选择了开放配置。**移调音高关系**与**重选配置音区**是两项决策，写清才不会把下降低音误判成错调。

若写完整旋律移调，则每个旋律音须按指定音程移动；只有级数进行没有规定旋律或声部音区。大调顺阶七和弦需再加七音，详见 [[06-基础乐理与指板/15-七和弦构成|七和弦构成]]；小调的v/V等不照搬此表，详见 [[06-基础乐理与指板/20-小调和声|小调和声]]。

## 常见错误及修正

- 把所有罗马数字都写大写：按表核对每一级的三和弦质量。
- 把 `vii°` 写成 `vii`：减号是质量信息，不能省略。
- 在 C 大调构成中混入升降音：先确认三项都来自 C 大调音集合。
- 认为级数自动决定伴奏效果：另行检查节奏、音色、旋律和段落功能。

## 分级练习

### 一级：辨认

R1. G调的A C E应写ii还是II？F♯ A C为什么不能省略减号？单有I–vi–IV–V能知道每个和弦持续几拍吗？

### 二级：推导

D1. 写D大调七个顺阶三和弦，每个都列组成音及级数。尤其检查第三、第七级。

### 三级：应用

A1. 把C–G–Am–Em的I–V–vi–iii移到F大调，写和弦名与组成音；选用吉他配置时，说明“和弦关系保留”和“每条声部等距移动”是否是同一个要求。

### 答案与解析

- R1：ii，因为A→C小三度；F♯→C减五度，所以vii°包含必要质量信息。级数串本身不提供时值，需要另写拍号和更换位置。
- D1：I D F♯ A（D）；ii E G B（Em）；iii F♯ A C♯（F♯m）；IV G B D（G）；V A C♯ E（A）；vi B D F♯（Bm）；vii° C♯ E G（C♯dim）。先从D音阶隔音取值再检查0/4/7等性质。
- A1：F C Dm Am，组成F A C、C E G、D F A、A C E。关系保留不自动规定音区，重配吉他时可换八度；若题目要求完整声部移调，就必须逐音保持指定音程，而不是只换和弦名。

## 自我检查标准

- 我能无遗漏写出大–小–小–大–大–小–减的质量模式。
- 我能准确写出 C 大调七个三和弦及其音名构成。
- 我能正确使用罗马数字大小写与 `vii°` 的符号。
- 我能说明级数保存关系，但不会自动决定节奏、旋律或情绪。
