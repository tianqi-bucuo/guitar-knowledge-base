# 全音与半音

## 学习目标与先修知识

请先完成 [[06-基础乐理与指板/指板上的音名|指板上的音名]]。本页把相邻品的物理距离、自然音间距和升降记号放在同一张单弦地图里；完成后，你应能从任一自然音找出上方半音与全音目标，并保留正确拼写。

> 安全边界：本页只提供一般性乐理与吉他练习信息，不用于诊断或治疗。弹奏出现疼痛、麻木或针刺感、无力、肿胀、动作控制下降或明显不适时立即停止；症状持续、反复或加重时，请向合格医疗专业人士求助。[^safety-bapam]

## 核心概念

半音是本课程常规十二平均律语境使用的最小距离。同一根弦上相邻一品相差一个半音，两品相差一个全音。[^circle-yamaha] 这只是入门吉他品位关系，不讨论微分音或硬件音准误差。

E–F、B–C 是相邻自然音中的半音，其余相邻自然音字母之间为全音。[^steps-puget] 因此不能把“相邻字母”一概理解成全音。

升号把音升高半音，降号把音降低半音，还原号取消此前的升降作用。[^accidentals-puget] 本页只说明符号方向，不展开谱面中的作用范围或双升双降。

在当前等温吉他品位语境，C♯ 与 D♭ 等不同拼写可以落在同一品位、指向同一发声目标；拼写仍保留不同的音阶或和声角色，不能无条件说它们“完全相同”。[^enharmonic-puget]

## 图示与操作步骤

下表是本站原创的单弦核对表；位移中的正号表示向琴身方向移动。

| 起点 | 半音目标 | 全音目标 | 单弦位移   |
| ---- | -------- | -------- | ---------- |
| E    | F        | F♯       | +1 / +2 品 |
| B    | C        | C♯       | +1 / +2 品 |
| C    | C♯ 或 D♭ | D        | +1 / +2 品 |
| G    | G♯ 或 A♭ | A        | +1 / +2 品 |

操作时先选一根弦和起点，向琴身走一品并写半音目标，再从起点走两品写全音目标。最后检查目标字母是否符合当前问题，而不是只报品格差。

## 常见错误及修正

- 把所有相邻自然音字母都当全音：单独记住 E–F 与 B–C 两个自然半音。
- 把一个品格说成全音：在同一弦重新数，一品半音、两品全音。
- 无条件说 C♯ 与 D♭ 完全相同：补上“当前等温、同一品位发声目标”的限定，并保留拼写角色。
- 只写位移不写目标音名：每次同时记录起点、距离、目标拼写和品位变化。

## 分级练习

以下是本站原创练习，答案必须同时包含距离与拼写。

### 第一级：辨认

判断 E–F、B–C、C–D、G–A 是全音还是半音，并说出依据；只凭相邻字母猜测就重新核对规则。

### 第二级：映射

在同一弦从表中起点找半音和全音目标，记录品位变化与拼写。若把一品当全音，退回第一级。

### 第三级：整合

说明 G 大调若把第七个字母写成 F，为何需要升成 F♯ 才能让最后一步 F♯→G 成为半音。若只说“因为在同一品”，退回第二级补上音名关系。

## 自我检查标准

- 我能不看图说出 E–F、B–C 两个自然半音。
- 我能在同一弦准确解释一品与两品分别对应什么距离。
- 我能给出 C♯/D♭ 的等音例，并说明限定语境与拼写差异。
- 我不会只凭品格差跳过目标音名。
