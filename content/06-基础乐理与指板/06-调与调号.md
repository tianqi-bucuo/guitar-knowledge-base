# 调与调号

## 学习目标与先修知识

请先完成 [[06-基础乐理与指板/05-大调音阶|大调音阶]]。本页不要求先会歌曲移调：先把主音中心、调内音集合和谱首记号分开，再用旋律落点判断调号没有告诉你的信息。

## 核心概念

本页从大调出发，把“调”理解为围绕某个主音组织旋律与和声的语境；调号是在谱首记录固定升降音的书写简记。[^key-signatures-puget] 两者相关却不是同一个概念，调号不能代替主音与实际音乐语境；调内也允许有临时变化音。

关系大小调可以共享调号，所以只看调号不能总是唯一确定调性，具体构造在 [[06-基础乐理与指板/11-小调音阶|小调音阶]]。C 大调调号没有升降音，意思是它的调号内容为“无”，不是没有调号概念。调号也可服务于调式音乐，所以“一个调号只可能有两个中心”仅是大小调练习里的候选筛选，不是所有音乐的定律。[^key-context][^minor-context]

临时记号写在具体音符附近，改变局部音高或拼写；它不同于谱首的调号。[^accidentals-puget] 同样，变调夹品位也不是调名：必须结合手上按法与升高距离，另算实响调或实响和弦。

## 图示与操作步骤

下表是本站原创核对表，音阶拼写与调号内容必须逐字母对应。

| 大调   | 音阶拼写        | 调号升降音 |
| ------ | --------------- | ---------- |
| C 大调 | C D E F G A B   | 无         |
| G 大调 | G A B C D E F♯  | F♯         |
| D 大调 | D E F♯ G A B C♯ | F♯、C♯     |
| F 大调 | F G A B♭ C D E  | B♭         |

构造时先写七个依次出现的字母，再套大调全半音公式，最后把全曲反复需要的升降音收进调号列。对照变调夹时另写“按法”和“实响”，不要拿夹位替代调名。

### 调号如何作用于实际音

两个升号F♯、C♯表示各个音区的F、C默认升高，不仅是谱首那条线上的音。D调旋律写D4 E4 F4（未另加临时记号）时，第三音实际应读F♯4；若作者要F自然，须用还原记号。临时改变这一个音不等于整首自动换调。调号的升号顺序F C G D A E B、降号顺序B E A D G C F，用 [[06-基础乐理与指板/12-关系调同主音调与五度圈|五度圈]] 可解释，不必把字母顺序当无缘由口令。[^key-context]

### 同一音集合，两个落点

原创短句甲：E4 G4｜B3 C4（每音四分，C4再延长二分），低音最后落C3；乙：C4 B3｜G3 A3（同节奏，A3延长），低音最后落A2。两句都可不加调号升降，甲的B→C与低音C支持C中心，乙的G→A与低音A支持A中心。单凭四个音仍不足以断言整首调性，但比“第一音是什么调就是什么”有更具体的证据。后续若不断回到C或A，并有对应和声收束，判断才更稳。

吉他可先分别弹2弦5品E4与2弦1品C4开头，再弹各句末尾；不需要先按完整和弦。注意C3在5弦3品、A2在5弦空弦。只列音集合会漏掉时值、句末与低音的强调作用。

## 常见错误及修正

- 把“无升降号”说成“没有调号概念”：准确写成 C 大调调号内容为无。
- 把一次临时升号当整个调号：确认它出现在谱首还是具体音符旁。
- 把夹二品直接叫 D 调：同时记录按法、升高距离与实响结果。
- 看到相同调号就断言唯一调性：补上主音中心与上下文证据。

## 分级练习

### 一级：辨认

R1. 调号为F♯，某小节出现临时C♯，能否立即认定已转到D大调？为什么只看第一音E也不能立刻判定E小调？

### 二级：推导

D1. 在D大调调号下读F3、F4、C5（均未另加临时记号）；写实际音名，再说明怎样记出F4自然音。

### 三级：应用

A1. 将“同一音集合，两个落点”两句分别抄出，圈出支持C或A中心的证据，并写一句保留意见。若在甲句中偶然经过F♯4，你会改变哪些判断？

### 答案与解析

- R1：不能。临时C♯只说明局部音高改变，可能是装饰或局部和声所需；还须看后续是否以D为中心。E也可能是G大调六级，开始音只是证据之一，不是定调按钮。
- D1：F♯3、F♯4、C♯5。调号跨音区有效；要F4自然，在该音前写还原记号，不是把谱首整个F♯删去。
- A1：甲的B3→C4、C4较长及低音C3支持C；乙的G3→A3、长A3及低音A2支持A。保留意见：短句不能代替整段调性证据。甲里出现一次F♯须记录为变化音，并考察它如何进行；不自动抹掉已有C中心证据。可回到原句弹奏比较，但不是以“听起来开心”作为证明。

## 自我检查标准

- 我能分别定义调、调号和临时记号，而不把三者互换。
- 我能准确写出 C/G/D/F 四行音阶与调号内容。
- 我能解释为什么相同调号不总能唯一确定调性。
- 我不会把变调夹品位直接当作调名。
