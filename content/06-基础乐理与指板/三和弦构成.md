# 三和弦构成

## 学习目标与先修知识

请先完成 [[06-基础乐理与指板/音程入门|音程入门]]、[[06-基础乐理与指板/大调音阶|大调音阶]] 与 [[02-和弦系统/和弦图读法|和弦图读法]]。本页把“和弦如何构成”和“吉他上如何按响”分开；完成后，你应能由根音关系判断大、小、减、增四类三和弦。

> 安全边界：本页只提供一般性乐理与吉他练习信息，不用于诊断或治疗。弹奏出现疼痛、麻木或针刺感、无力、肿胀、动作控制下降或明显不适时立即停止；症状持续、反复或加重时，请向合格医疗专业人士求助。[^safety-bapam]

## 核心概念

三和弦由三个不同音高类别组成，按三度叠置时标为根音、三音、五音。[^triads-puget] 吉他 voicing 可以把其中某个音重复在多根弦上，所以弹响六根弦仍可能表达一个只有三个音高类别的三和弦。

本页所有公式都从根音量半音：先确认根音，再分别量到三音和五音；不能从实际最低发声音直接套公式。[^identify-intervals-puget] 指法图回答“这次怎样在吉他上发声”，构成表回答“和弦包含哪些音高类别”，二者不能互相替代。

大、小、减、增是音程结构，不用“快乐”或“悲伤”代替。表内“音程构成”也都从根音量起，并非相邻两个三度的距离描述。

## 图示与操作步骤

下表是本站原创构成表。先读示例音名，再分别检查根到三音、根到五音。

| 类型     | 从根音算半音 | 音程构成        | 示例   |
| -------- | ------------ | --------------- | ------ |
| 大三和弦 | 0–4–7        | 大三度 + 纯五度 | C–E–G  |
| 小三和弦 | 0–3–7        | 小三度 + 纯五度 | A–C–E  |
| 减三和弦 | 0–3–6        | 小三度 + 减五度 | B–D–F  |
| 增三和弦 | 0–4–8        | 大三度 + 增五度 | C–E–G♯ |

操作顺序是：指定根音；按字母隔一个音写三音与五音；计算两者相对根音的半音；最后按表判质量。若另从相邻叠置看，四类依次为“大三度+小三度”“小三度+大三度”“小三度+小三度”“大三度+大三度”。

## 常见错误及修正

- 把“三个音高类别”误作“只能弹三根弦”：列出实际按法里的重复音。
- 从最低实响音而非根音量公式：先确定和弦根音，再标零点。
- 用情绪标签判断质量：回到三音、五音相对根音的半音。
- 拿和弦图证明构成：图只说明 voicing，仍须写出音名与音程。

## 分级练习

以下是本站原创练习，判断结果都要能回到根音公式。

### 第一级：辨认

从表中任选音名组合，写出根音到三音、五音的半音数，再判断质量；先猜名称而不量关系就重做。

### 第二级：映射

在 C 大调音集合内构造 C、Dm、Bdim，逐项标根音、三音、五音。若混入调外音，退回第一级核对音名。

### 第三级：整合

对照现有 C、Am 和弦按法，列出重复音，并解释重复不会改变三和弦的三个音高类别。若仍以琴弦数定义和弦，退回第二级。

## 自我检查标准

- 我能准确写出四类三和弦的 `0–4–7`、`0–3–7`、`0–3–6`、`0–4–8`。
- 我能从根音量到三音和五音，不把相邻叠置间距误写进公式。
- 我能解释为什么常见六弦按法仍可表达三和弦。
- 我不会用情绪词或单张指法图代替音高构成证明。
