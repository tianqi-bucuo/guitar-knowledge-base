# 挂留和弦与附加音和弦

## 学习目标与先修知识

先完成 [[06-基础乐理与指板/15-七和弦构成|七和弦构成]]。本页让你看到符号就能问对问题：“第三音还在吗？七音有没有？哪个音是新增，哪个音被替代？”吉他上相似的按法可能回答不同问题，不能只按听感或手型命名。

## 核心概念

### sus是替代第三音，add是保留后再添加

常用流行符号Csus2为C D G，以大二度D替代三音E；Csus4为C F G，以纯四度F替代E。单写Csus通常指sus4。[^sus] 它们没有第三音，不能单靠音集合判断通常意义上的大、小三和弦性质。若加入E同时保留D，则是附加音结构Cadd9，而不是继续叫Csus2。

Cadd9的9是相对根音的大九度音级D，公式1 3 5 9；实际配置可以把D放在较低音区，不要求永远高于所有其他音。2与9有八度关系，但add与sus的差别首先是三音有没有，不能仅凭D放高还是放低决定名称。[^add]

### Cadd9与C9差在七音

单写C9在本课采用常见和弦标记惯例：C属七加大九，完整音集合C E G B♭ D。Cadd9不默认含七音，只有C E G D。Cmaj9为C大七加大九，C E G B D；maj在这里说明七音B为大七，不是说C9的九音较小。[^add]

吉他常省略五音以容纳三、七、九音；分析符号所指定的结构和这一刻实际发出的配置应分开写。省略G不把C9变成Cadd9，七音B♭是否保留才是这个对比的关键。本页不讨论所有复杂延伸和弦的省略规范。

### sus符号与“挂留音”不是同一个判据

写Csus4只规定一个和弦音集合，未规定前后时间。声部挂留则是过程：某音先在前一个和声中准备，延续到新和声形成不协和，再级进解决。[^suspension] 例如F和弦时F4为组成音，低音换C3后让F4保持，再下行E4，就具备4–3挂留的准备、延留与解决。若从静止直接弹Csus4而不解决，仍可正确使用sus符号，却不能凭名称声称出现了完整古典挂留过程。

## 图示与操作步骤

### 符号核对

音集合列是理论完整组成，不代表唯一配置；“三音／七音”以C根为准。

| 符号  | 音集合     | 三音 | 七音 |
| ----- | ---------- | ---- | ---- |
| Csus2 | C D G      | 无   | 无   |
| Csus4 | C F G      | 无   | 无   |
| Cadd9 | C E G D    | E    | 无   |
| C9    | C E G B♭ D | E    | B♭   |
| Cmaj9 | C E G B D  | E    | B    |

按步骤解符号：先认根音C；sus时替换三音，add时保留三音；若单写9，补相应七音；最后检查实际配置有没有省略。迁移D根音：Dsus2=D E A，Dsus4=D G A，Dadd9=D F♯ A E，D9=D F♯ A C E。先保留D F A C E的字母关系再核对性质，不要将C例整体照搬字母。

### 吉他配置核对

标准定弦、无变调夹，tuple按6→1弦；实响也按发声弦序写。

| 符号／说明   | 六到一弦    | 实响音高       |
| ------------ | ----------- | -------------- |
| Csus2        | x-3-0-0-1-3 | C3 D3 G3 C4 G4 |
| Csus4        | x-3-3-0-1-1 | C3 F3 G3 C4 F4 |
| Cadd9        | x-3-2-0-3-3 | C3 E3 G3 D4 G4 |
| C9（省五音） | x-3-2-3-3-x | C3 E3 B♭3 D4   |

若Csus2仍让1弦空弦E4响，三音E重新加入，实际更接近Cadd9的配置；所以“我按了sus形”不能代替“哪些弦真的响”。C9行虽只有四根弦，B♭3与D4分别保留七、九音，明确省略G。小横按困难时只分开点弹音，不强求一次全部按住。

### 用一个变量做比较

先在纸上固定C3 G3 D4，再选择“不加E”与“加E4”，前者为Csus2音集合，后者为Cadd9。再固定C3 E3 G3 D4，分别不加七音、加B♭3、加B3，得到add9、9、maj9。一次只改变一项，才知道符号差别来自哪里；不必找完全相同的手型来完成概念比较。

## 常见错误及修正

- sus2和add9都看成“加个D”：前者替换E，后者保留E。
- 认为C9只是C加D：完整C9还含B♭，没有七音应考虑add9。
- 见maj9就把D再升高：maj限定七度，本例九音仍D。
- 强迫所有sus都解决：和弦符号不自带前后句法；先区分静态集合与动态挂留。

## 分级练习

### 一级：辨认

R1. C D G、C E G D、C E B♭ D分别如何标记？最后一个省略了哪个音？

### 二级：推导

D1. 写Gsus4、Gadd9、G9、Gmaj9的完整音集合；指出决定后两者差别的音。

D2. 某旋律在C和弦开始时直接奏F4，再走E4，前一个和声没有F4延留，能否只因F→E就确认完整挂留？

### 三级：应用

A1. 检查本页Csus2形：如果误将1弦3品放开为空弦，同时其余弦都响，列实际音高与音集合，提出两种修正方向——保留目标Csus2，或接受新和弦并改标记。

### 答案与解析

- R1：Csus2、Cadd9、C9（省五音G）。最后一个保留小七B♭，不能因为少一根弦就改叫add9。
- D1：G C D；G B D A；G B D F A；G B D F♯ A。后两者差在F／F♯的小七／大七，不在共同九音A。
- D2：不能。完整挂留还须有准备并延留进新和声的过程；直接起F再解决可能属于其他非和弦音用法，须看节奏与前后音。静态也可标sus色彩，但两种分析不等价。
- A1：C3 D3 G3 C4 E4，音集合C D E G，为Cadd9的一种配置。若保留Csus2，可恢复1弦3品G4或让1弦不响；若接受E4，改标Cadd9并说明配置。评价看实际三音有无与其他音是否仍清楚，不以手型名称自证。

## 自我检查标准

能写出三音、七音的有无，并区分静态符号和时间过程；能核对每个品位实响。若七度性质不稳回 [[06-基础乐理与指板/15-七和弦构成|七和弦构成]]。疼痛、麻木或控制下降时停止弹奏，见 [[08-保养安全与排错/01-疼痛疲劳与停止练习边界|停止练习边界]]。
