# 音高音名与唱名

## 学习目标与先修知识

## 核心概念

音高描述声音的高低关系；音名是标签。A–G 七个字母循环，同一个字母会在不同八度再次出现，所以只写 `E` 不能唯一指出 `E2` 或 `E4`。科学音高记号把字母与八度数字放在一起，用来区分具体音区。[^octave-puget]

音级表示一个音在当前调内的位置，会随主音改变。本站采用首调唱名：当前调的 `1–7` 级唱作 `do–re–mi–fa–sol–la–ti`；固定唱名是另一种体系，本路线不把两者混进同一道练习。[^solfege-libretexts] 因而 C 不是永久等同 do，只有在 C 大调的首调语境里 C 才是 do。

标准定弦从低音六弦到高音一弦是 `E–A–D–G–B–E`。[^fretboard-yamaha] 加上科学音高记号，本页写成：`6→1弦：E2 | A2 | D3 | G3 | B3 | E4`。两根 E 弦音名相同，却相差两个八度，不是同一个具体音高。

## 图示与操作步骤

下表是本站原创的概念辨析表。先读“回答的问题”，再选择合适的记号类别；不要从示例反猜类别。

| 回答的问题         | 记号类别     | 示例           | 本页解释                    |
| ------------------ | ------------ | -------------- | --------------------------- |
| 这个声音高还是低？ | 音高关系     | 后一个声音更高 | 比较听觉/振动结果，不是名字 |
| 它属于哪个字母？   | 音名         | E              | A–G 循环                    |
| 是哪个音区的 E？   | 科学音高记号 | E2、E4         | 同名但不是同一具体音高      |
| 在当前调里排第几？ | 音级         | 1、3、5        | 依当前主音变化              |
| 如何唱读音级？     | 首调唱名     | do、mi、sol    | 本站约定 1=do               |

操作时先指出弦号，再说空弦音名和八度；进入调性问题后，另起一句说音级与唱名。这样可以看见每个答案正在解决什么问题。

## 常见错误及修正

- 把 E2 与 E4 当成同一具体音高：回答时补上八度号，并比较两根 E 弦。
- 永久把 C 等同 do：先说当前主音；只有 C 大调的首调语境才得到 `C=do`。
- 把弦号当音名：先指“第六弦”，再说它的空弦音名 E2。
- 把和弦名 C 与音级 I 混用：前者命名具体和弦，后者说明它在当前调中的位置。

## 分级练习

以下是本站原创练习，不设置统一速度、时长或重复配额。

### 第一级：辨认

把 `E`、`E2`、`3`、`mi` 分别归入音名、科学音高记号、音级和首调唱名，并口述判定依据。分类错误就重新读表头。

### 第二级：映射

从六弦到一弦口述 `E2 A2 D3 G3 B3 E4`，再反向指出两根 E 弦为何同名而音区不同。若弦号与音名混淆，退回第一级。

### 第三级：整合

选已学的 C 大调和弦，分别说“和弦名 C”和“在 C 大调中音级 I”回答什么问题；再换一个假定主音，说明 do 会随调改变。任何概念互换就退回第二级。

## 自我检查标准

- 我能解释为什么只写 `E` 不足以唯一指定 `E2` 或 `E4`。
- 我能从六弦到一弦准确说出 `E2 A2 D3 G3 B3 E4`。
- 我能说明音名、音级与首调唱名分别依赖什么信息。
- 我不会把 C 永久写成 do，也不会把弦号当成音名。
