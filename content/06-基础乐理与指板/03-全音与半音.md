# 全音与半音

## 学习目标与先修知识

请先完成 [[06-基础乐理与指板/02-指板上的音名|指板上的音名]]。本页把相邻品的物理距离、自然音间距和升降记号放在同一张单弦地图里；完成后，你应能从任一自然音找出上方半音与全音目标，并保留正确拼写。

## 核心概念

半音是本课程常规十二平均律语境使用的最小距离。同一根弦上相邻一品相差一个半音，两品相差一个全音。[^circle-yamaha] 这只是入门吉他品位关系，不讨论微分音或硬件音准误差。

E–F、B–C 是相邻自然音中的半音，其余相邻自然音字母之间为全音。[^steps-puget] 因此不能把“相邻字母”一概理解成全音。

升号把所写字母的自然音升高半音，降号把它降低半音，还原号恢复该字母的自然音。双升提高两个半音、双降低两个半音；这里以 `♯♯`、`♭♭` 表示双记号，实际乐谱也使用专门的双升符号。[^accidentals-puget] 例如F♯→F♮向下半音，B♭→B♮却向上半音，所以“还原”不是固定向下。完整谱面的临时记号范围在 [[06-基础乐理与指板/09-五线谱简谱与六线谱|读谱课]] 说明。

在当前十二平均律语境，C♯ 与 D♭ 等不同拼写可以落在同一品位、指向同一发声目标；拼写仍保留不同的音阶或和声角色，不能无条件说它们“完全相同”。[^enharmonic-puget]

## 图示与操作步骤

下表是本站原创的单弦核对表；位移中的正号表示向琴身方向移动。

| 起点 | 半音目标 | 全音目标 | 单弦位移   |
| ---- | -------- | -------- | ---------- |
| E    | F        | F♯       | +1 / +2 品 |
| B    | C        | C♯       | +1 / +2 品 |
| C    | C♯ 或 D♭ | D        | +1 / +2 品 |
| G    | G♯ 或 A♭ | A        | +1 / +2 品 |

操作时先选一根弦和起点，向琴身走一品并写半音目标，再从起点走两品写全音目标。最后检查目标字母是否符合当前问题，而不是只报品格差。

### 从距离得到音高，再按问题选择拼写

以2弦1品C4为起点，上方一个全音为3品D4：C→C♯→D经过两个半音。以2弦5品E4为起点，上方一个半音为6品F4；若问题要求“把E升高”，则应写E♯4。两个写法在本课程的十二平均律中对应同一发声目标，但保留的字母身份不同。

同样，C4上方三半音落在2弦4品。若要求“C上方某个D”，字母要保留D，得到D♯；若要求“某个E”，得到E♭。下一课将因此分别判为增二度、小三度。音高定位回答“按哪品”，拼写回答“这个音在关系中叫什么”，二者不能互相代替。

下降时也要明确方向：G4下方全音是F4；F4下方半音是E4。不是把字母机械往回退一位就一定下降全音。升降号不是黑键专用名称，E♯和C♭都可能合理；是否使用它们由音阶、音程和声部关系决定。

### 吉他上的两种核对

先在同弦比较2弦1品C4、2品C♯4、3品D4，得到半音、全音；再比较3弦4品B3和2弦0品B3，两手位置差很大却是零音高距离。可见“一品半音”必须带**同一弦、同一调弦、未推弦**这些条件。跨弦距离要从两个实际音高算，不能量手指在指板上相隔多少厘米。

## 常见错误及修正

- 把所有相邻自然音字母都当全音：单独记住 E–F 与 B–C 两个自然半音。
- 把一个品格说成全音：在同一弦重新数，一品半音、两品全音。
- 无条件说 C♯ 与 D♭ 完全相同：补上“当前十二平均律语境、同一品位发声目标”的限定，并保留拼写角色。
- 只写位移不写目标音名：每次同时记录起点、距离、目标拼写和品位变化。

## 分级练习

以下是本站原创练习，答案必须同时包含距离与拼写。

### 一级：辨认

R1. E–F、B–C、C–D、G–A 各为多少半音？还原F♯与还原B♭是否都向下？

### 二级：推导

D1. 从F4上行全音，从B3上行半音，各到什么自然音？将E4升高半音、将B4降低两半音，应保留什么字母拼写？

### 三级：应用

A1. 在2弦以C4为起点找上方三个半音。写出目标品、两种等音名称；若题目限定目标字母D，能否用E♭替代书面答案？再解释为何3弦4品与2弦0品不符合“位置相邻才可能半音”的猜想。

### 答案与解析

- R1：依次1、1、2、2。F♯还原为F下降半音；B♭还原为B上升半音，还原的方向由原记号决定。
- D1：F→F♯→G，得到G4；B3→C4，换音区号。保留字母时为E♯4、B♭♭4；后两者分别与F4、A4等音，但不是用新字母取代原拼写。
- A1：从1品前进3品到4品，实响可写D♯4或E♭4。限定D时必须写D♯4，因为E♭改变了字母跨度。3弦4品与2弦0品都是B3，音高差为零，指板几何距离并不等于音高距离。

## 自我检查标准

- 我能不看图说出 E–F、B–C 两个自然半音。
- 我能在同一弦准确解释一品与两品分别对应什么距离。
- 我能给出 C♯/D♭ 的等音例，并说明限定语境与拼写差异。
- 我不会只凭品格差跳过目标音名。
