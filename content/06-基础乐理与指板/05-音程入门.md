# 音程入门

## 学习目标与先修知识

## 核心概念

音程描述两个音高之间的距离。旋律音程先后发声，和声音程同时发声；同时出现两个音还不自动构成一个完整和弦。[^intervals-puget]

完整名称需要级数与性质。第一步先数包含首尾的音名字母，例如 C–E 数 C、D、E 得三度；第二步再数半音判定大、小或纯等性质。[^identify-intervals-puget] 品格数可以帮助量半音，却不能替代字母拼写。

相同半音数也不能跳过拼写：C–E♭ 是小三度，而 C–D♯ 虽同为三个半音，字母跨度只有二度，应叫增二度。[^enharmonic-puget][^aug-dim] 在十二平均律中，音程的声音距离可以相同，完整名称仍可不同，因为名称还描述字母关系。

### 两套计数，各做各的工作

以D4→B4为例，先数 `D E F G A B`，含首尾共六个字母位置，是六度。再把距离逐段相加：D–E为2，E–F为1，F–G为2，G–A为2，A–B为2，合计9半音，因此是大六度。若上音改为B♭4，字母仍是六度，距离减为8，成为小六度。若上音改成C♭5，虽然与B4等音，字母D到C却是七度，不能仍叫六度。

计半音是走了几步，起点到自己0步；计度数是跨过几个字母位置，起点自己占1个。这样就不会把八度误算为“七度”，或把同音误叫“零度”。先后发声可分别说上行／下行；本课表格统一从低音向高音命名，不能略掉音区而误读方向。

### 纯、大、小、增、减怎样相邻

一、四、五、八度属于纯音程一组；二、三、六、七度属于大／小一组。固定字母跨度时：纯音程扩大半音为增，缩小半音为减；大音程缩小半音是小，小音程再缩小半音才是减，大音程扩大半音为增。[^aug-dim] 不能把“大三度减半音”直接叫减三度，也没有常规的“小五度”。

例：F4–B4有四个字母、6半音，比纯四度5半音多1，是增四度；B3–F4有五个字母、6半音，比纯五度7半音少1，是减五度。C4–B♭♭4有七个字母、9半音，比小七度10少1，是减七度；即使B♭♭4与A4等音，也不能写成大六度。

## 图示与操作步骤

### 音程对照

本站原创核对表统一用C4为低音，前面的推导方法可迁移到任意根音。这里以 `♭♭` 表示双降；每行须同时核对字母跨度与半音数。

| 两端实响音高 | 音程名 | 半音数 |
| ------------ | ------ | ------ |
| C4–C4        | 纯一度 | 0      |
| C4–D♭4       | 小二度 | 1      |
| C4–D4        | 大二度 | 2      |
| C4–D♯4       | 增二度 | 3      |
| C4–E♭4       | 小三度 | 3      |
| C4–E4        | 大三度 | 4      |
| C4–F4        | 纯四度 | 5      |
| C4–F♯4       | 增四度 | 6      |
| C4–G♭4       | 减五度 | 6      |
| C4–G4        | 纯五度 | 7      |
| C4–A♭4       | 小六度 | 8      |
| C4–A4        | 大六度 | 9      |
| C4–B♭♭4      | 减七度 | 9      |
| C4–B♭4       | 小七度 | 10     |
| C4–B4        | 大七度 | 11     |
| C4–C5        | 纯八度 | 12     |

实际判断时先把两个音名写全，包含首尾数字母得到级数，再在一根弦或可靠音名表上数半音，最后把性质放在级数前。任何一步缺失都不算完整答案。

### 换根音与吉他核验

求G3上方大三度：先数G–A–B，目标字母B；G→A两半音、A→B两半音，得到B3。吉他上3弦0品G3→4品B3，既符合4半音也符合三度。求E4上方小三度，先选G字母，E→F为1、F→G为2，总3半音，得到G4，第一弦0→3品即可验证。

换成同时发声时，可弹3弦空弦G3和2弦空弦B3，仍是大三度；不能因为两指都在“0品”就以为距离是零。写上“G3–B3，大三度，4半音”，比只记手型可靠。若暂不弹琴，写出空弦起点和累计品数同样能完成核验。

## 常见错误及修正

- 从零开始数“几度”：级数按字母包含首尾计数，C 到 C 是一度。
- 只看半音数忽略字母：先写目标拼写，防止把 C–D♯ 自动叫小三度。
- 把同时弹的两个音直接叫和弦：本页只称和声音程，三和弦还需要三个音高类别。
- 跨弦只数手指距离：先确认两端音名，再计算字母跨度和半音数。

## 分级练习

以下是本站原创练习，完整回答必须同时包含两种计数。

### 一级：辨认

R1. C4–D♯4与C4–E♭4同为三个半音，为什么名字不同？C4–B♭♭4与C4–A4又怎样区别？

### 二级：推导

D1. 写出D4上方小六度、F4上方大七度、B3上方减五度，每题列字母序列和半音数。

D2. E4–G♯4缩小半音、保持两个字母不变时，若固定E4，应怎样改写上音？新名称是什么？

### 三级：应用

A1. 核对3弦0品与2弦0品的和声音程；将2弦改为1品，低音不变，重新命名。另在1弦空弦至3品验证E4–G4，写出“跨弦”和“同弦”的计算为何不能共用一个品差公式。

### 答案与解析

- R1：前两者字母跨度分别2和3，是增二度与小三度；后两者分别7和6，都是9半音但为减七度与大六度。正确拼写不是可随意省略的信息。
- D1：D E F G A B，共六度，目标B♭4，8半音；F G A B C D E，共七度，目标E5，11半音；B C D E F，共五度，目标F4，6半音。F到E跨过C换号，不能漏写E5。
- D2：G♯4降半音为G4，得到E4–G4小三度，3半音；从大变小并非直接变减。
- A1：G3–B3为大三度4半音；G3–C4为纯四度5半音；E4–G4为小三度3半音。同弦只需品数差，跨弦还须加上空弦音高差；两个0品不代表同音。

- 我能在每个答案中同时给出字母跨度与半音数。

- 我能解释 C–D♯ 不能只凭三个半音自动叫小三度。
- 我不会把和声音程与完整和弦混为一谈。
