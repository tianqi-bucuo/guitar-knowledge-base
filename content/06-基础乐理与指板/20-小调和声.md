# 小调和声

## 学习目标与先修知识

先会 [[06-基础乐理与指板/11-小调音阶|小调三种形式]]、[[06-基础乐理与指板/08-顺阶和弦与级数|顺阶构造]] 与 [[06-基础乐理与指板/18-和声功能|功能]]。目标是解释为什么同一首A小调音乐可同时出现Em和E7，且不把后者误当成“自然小调本来就有G♯”。

## 核心概念

### 自然小调先修表，不是全部可用和弦

从A B C D E F G逐级隔音叠置，得到Am、Bdim、C、Dm、Em、F、G。这里采用**小调内部级数**i、ii°、III、iv、v、VI、VII，III的C不用另写♭。若用同主音大调参照则C/F/G常写♭III／♭VI／♭VII；两者表达同一音高，不能看见两种写法就以为谁把音多降了一次。[^minor]

| 内部级数 | 自然小调组成 | 和弦 |
| -------- | ------------ | ---- |
| i        | A C E        | Am   |
| ii°      | B D F        | Bdim |
| III      | C E G        | C    |
| iv       | D F A        | Dm   |
| v        | E G B        | Em   |
| VI       | F A C        | F    |
| VII      | G B D        | G    |

### 升高导音为何改变属和弦

E–G–B中的G距主音A为全音；升成G♯后，G♯→A有半音趋向，E–G♯–B成为大三和弦V。再加D（E上方小七），得到E7=V7。D通常可下行到主和弦三音C，配合G♯上行A，强化回到Am的连接。自然v与功能性V可以各有音乐用途，前者不因缺导音就“错”。[^minor]

### 七级也必须说明用哪个根音

A自然小调的VII是G B D；升高导音上的vii°是G♯ B D，两者根音不同、性质不同。再叠F得G♯ B D F全减七；从自然G上加F得G B D F属七结构，但在A小调它不是V7。同一个“7”只说明结构，功能必须根据根音、目标和语境判断。

不要把三种小调音阶各自生成的和弦机械混成“随便替换表”。实际使用第六、七级哪个版本取决于旋律与和声：一条G自然旋律长音与E7的G♯同时出现，会形成半音冲突，可能是有意色彩，也可能是编配疏漏，要听和说明，不能靠调名保证兼容。

## 图示与操作步骤

### 小调属和弦核对

以下均在A小调，第三列是属根音E的三音。

| 级数 | 组成     | 三音 | 来源     |
| ---- | -------- | ---- | -------- |
| v    | E G B    | G    | 自然小调 |
| V    | E G♯ B   | G♯   | 升高七级 |
| V7   | E G♯ B D | G♯   | 升高七级 |

原创4/4四小节Am｜Dm｜E7｜Am，每和弦4拍；低音A2 D3 E2 A2，上方可取E4 F4 G♯4 A4各全音符。这是i–iv–V7–i，每小节主拍持续，句尾升高导音回主音。吉他G♯3可在3弦1品、A3在3弦2品，先将高声部整体降低八度做两音核对，不必硬弹原高音配置。

### 迁移E小调

E自然小调E F♯ G A B C D，对应Em F♯dim G Am Bm C D；升高第七级D为D♯后属和弦变B或B7，组成B D♯ F♯或B D♯ F♯ A。原创Em｜Am｜B7｜Em的两条关键线为D♯→E、A→G。不能把A小调的G♯直接套来当E小调导音。

标准B7 `x-2-1-2-0-2` 实响B2 D♯3 A3 B3 F♯4；有根、三、五、七四类，B重复。每弦核对后再尝试连接Em，不要求速度；纸上算音也可完成理论部分。

## 常见错误及修正

- A小调所有和弦都小：自然集合已有大三与减三和弦。
- 自然小调表里直接写E大三：须说明G♯来自升高第七级。
- 将G和G♯dim都叫“七级和弦”而不区分：写完整根音与采用的级数基准。
- 认为只要升七就已经转调：主音仍可A，变化音服务原调属功能。

## 分级练习

### 一级：辨认

R1. A小调的Em、E7、G、G♯dim各由哪些音组成？哪两个需要G♯？

### 二级：推导

D1. 在D小调写自然v、功能V7与导音减七和弦，保留正确七音拼写；并指出原调号中的降音是否消失。

### 三级：应用

A1. 为E小调的Em｜Am｜B7｜Em写每小节一个上方长音，末两音体现导音解决；再写一条在第三小节用D自然的替代旋律，说明它与B7三音的冲突如何检查。

### 答案与解析

- R1：E G B；E G♯ B D；G B D；G♯ B D。E7、G♯dim需升高导音，其余是自然集合。
- D1：v=A C E；V7=A C♯ E G；导音减七C♯ E G B♭。D小调调号B♭仍保留，升高的是C→C♯，不是删除所有降号。C♯到B♭为减七9半音。
- A1：G4 A4 D♯4 E4，均全音符，末两音半音上行；替代第三小节D4会与B7的D♯发生半音冲突。可改回D♯，或根据风格改和弦为自然Bm并接受较弱导音趋向，或明确设计变化音处理；不能只说“都在小调里就没问题”。

## 自我检查标准

能在D/E小调迁移v/V7，并说明变化音来自何处；能避免内部级数与大调参照混用。拼写不稳回 [[06-基础乐理与指板/11-小调音阶|小调音阶]]。弹奏疼痛、麻木或控制下降时停止，见 [[08-保养安全与排错/01-疼痛疲劳与停止练习边界|停止练习边界]]。
