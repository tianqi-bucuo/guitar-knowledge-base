# 更换琴弦

## 学习目标与先修知识

本页提供有条件的基础换弦流程，帮助你确认资料、松弦顺序与停止门槛。先修为 [[08-保养安全与排错/01-疼痛疲劳与停止练习边界|疼痛疲劳与停止练习边界]]、[[00-从这里开始/04-吉他调音与标准音|吉他调音与标准音]] 与 [[01-持琴与基础动作/01-认识民谣吉他|认识民谣吉他]]。身体警讯立即停止，不等待先修完成。

## 核心概念

> 安全边界：本页只提供一般性吉他保养与练习安全信息，不用于诊断、治疗或康复。弹奏或维护出现疼痛、麻木或针刺感、无力、肿胀、动作控制下降、过度疲劳或明显不适时立即停止；症状持续、反复或加重时，请向合格医疗专业人士求助。[^safety-bapam]

本页范围是支持钢弦的民谣吉他，不是所有吉他的完整换弦工艺。不要把钢弦装到不支持钢弦的琴上。弦规格改变可能需要专业 setup 评估；无法确认兼容性时，先问制造商或维修师。[^care-yamaha-booklet] 其他琴桥固定方式、弦钮形式也必须有相应型号说明，不能凭外观相似照搬步骤。

本站选择逐根处理，便于核对弦号与新旧弦，不宣称拆下全部琴弦必然损坏琴颈。实际松紧方向、绕弦圈数、剪弦余量与终端处理，均依具体琴型制造商说明；本页不给统一配方。新弦与废弦的断端尖锐，操作时脸避开弦与尖端方向。[^care-yamaha-owner]

琴桥翘起需先维修，不能重新上弦后看看会不会恢复。[^care-yamaha-storage] 更换新弦不是结构修复，也不能拿异常张力作为“尚未装稳”的理由继续拧紧。

## 图示与操作步骤

> 器材边界：仅做本页明确允许的观察和基础维护。琴颈调节杆、弦枕加工、品丝打磨、琴颈角度与结构修复交给合格维修人员；出现阻力、异常张力、结构裂缝或琴桥翘起时停止操作，不强扭、撬拔或继续上弦。[^care-yamaha-booklet][^care-yamaha-storage]

这组完整门槛是本站保守安全规则；来源支持专业处理类别与琴桥翘起不继续上弦，不是逐字列出全部触发项。下表为本站原创流程核对，不能替代具体琴型说明。任何一项条件缺失，就停在该阶段。

| 阶段         | 操作门槛                         | 允许的动作                                                   | 停止条件                                               |
| ------------ | -------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------ |
| 查型号       | 找到该琴型、固定方式与弦规格说明 | 准备制造商适用的新弦与工具                                   | 无法确认兼容或改变规格先问维修师[^care-yamaha-booklet] |
| 查结构与环境 | 身体无不适，琴无结构警讯         | 稳定保护琴体，脸避开弦与尖端方向[^care-yamaha-owner]         | 裂缝或琴桥翘起先维修，不上新弦[^care-yamaha-storage]   |
| 松旧弦       | 确认目标弦已完全松弛             | 依型号说明松弦后才拆除；不剪受张力的弦[^care-yamaha-booklet] | 方向不明、阻力或异常张力即停                           |
| 取固定件     | 已松弦且说明允许用户拆卸         | 仅依具体固定方式与适用工具拆除                               | 不以弦枕为支点撬拔，不强扭                             |
| 固定新弦     | 确认弦与固定方式匹配             | 按说明就位并轻柔确认，不敲打[^care-yamaha-booklet]           | 固定件异常移动或琴桥翘起即停                           |
| 绕弦与弦端   | 已读具体弦钮说明                 | 依说明处理穿孔、绕弦与余量                                   | 不套用统一方向、圈数或剪弦长度                         |
| 调音检查     | 新弦固定正常                     | 逐弦确认 6→1 弦 E2–A2–D3–G3–B3–E4                            | 超目标音区、异常张力或固定件异常即停                   |
| 完成收纳     | 各弦与结构检查通过               | 依说明安全处理弦端并收集尖锐废弦[^care-yamaha-owner]         | 不让断端伤手或脸，不强拉求稳定                         |

表中的 E2–A2–D3–G3–B3–E4 按低音六弦到高音一弦排列，依次对应第 6、5、4、3、2、1 弦。

先把说明放在可查看的位置，确认当前目标弦对应的新弦。松弦之后才进行拆除；不要为了省步骤剪受张力的弦。固定件拆装要采用制造商适用方式，若资料无法解释你的琴型，停止并求助。调音时同时确认弦号、音名与音区；看到音名相同不代表音区正确。

## 常见错误及修正

把所有琴的弦钮都想成同一转向，可能导致越松越紧。修正是回到具体说明确认视角与部件；方向不明即停，不用试转猜测。遇到固定件难取时，不以弦枕为支点撬拔、不敲打，也不强扭。

把换弦当成稳定性比赛而强拉新弦，会把尖端与张力风险带进流程。完成条件是固定正常、目标音区正确、结构无警讯及废弦安全收集，不是拉够某个次数。官方来源也有超出本课程范围的操作，不能只因“官方”就跳过型号与安全门槛。

## 分级练习

以下为本站原创门槛练习，按资料与状态推进，不要求人人实际换完才能过关。

### 第一级：核对资料与工具

查出自己的琴型、允许的弦规格、固定方式和弦钮说明，列出适用工具与停止条件。若有缺项，退回资料核对并问制造商或维修师，不开始拆弦。

### 第二级：不用操作逐项复述

保持琴原状，复述查结构、完全松弦、拆固定件、装弦、绕弦和调音的条件。说明为什么松弦必须在拆除或剪弦之前；资料不足时选择停止。

### 第三级：决定基础换弦或转交

资料充分、身体与琴状态正常且能确认各阶段门槛时，才依具体说明基础换弦。遇阻力、异常张力或结构警讯立即停止并转交维修师。不能确认时，选择专业处理就是完成决策。

## 自我检查标准

- 我能确认钢弦兼容性、具体琴型说明与适用工具，换规格先询问维修师。
- 我知道先完全松弦再拆除或剪弦，不剪受张力的弦。
- 我不会套用统一转向、圈数或余量，遇阻力即停。
- 我能识别裂缝或琴桥翘起需先维修，不重新上弦。
- 我能核对正确音区并避免弦端伤手或脸，安全收集废弦。
