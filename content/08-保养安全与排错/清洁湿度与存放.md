# 清洁湿度与存放

## 学习目标与先修知识

本页帮助你用干软布、环境记录和型号资料安排日常存放。先修是 [[08-保养安全与排错/弦距琴颈与品丝基础|弦距琴颈与品丝基础]] 与 [[01-持琴与基础动作/认识民谣吉他|认识民谣吉他]]，用于区分部件与结构问题；身体警讯立即停止，不以学完先修为条件。

## 核心概念

> 安全边界：本页只提供一般性吉他保养与练习安全信息，不用于诊断、治疗或康复。弹奏或维护出现疼痛、麻木或针刺感、无力、肿胀、动作控制下降、过度疲劳或明显不适时立即停止；症状持续、反复或加重时，请向合格医疗专业人士求助。[^safety-bapam]

型号无关的默认是用适合乐器的干软布轻擦汗污，留意布是否清洁及无硅成分。Yamaha 提醒有些涂层不适合硅成分；这里不提供油剂、家具抛光或钢丝绒处方。[^care-yamaha-basic] 不灌液、不自行加入清洁剂；难去污或漆面、指板材料不明时，查具体琴型制造商说明，缺资料问制造商或维修师。

琴盒提供物理保护，不自动保证湿度。先用湿度计记录室内或琴盒实测地点、日期、读数与变化，再依具体型号说明处理。[^humidity-taylor] Martin 与 Taylor 的 45–55% RH 是品牌建议例，不能当作所有琴的精确通用标准，也不能当作湿度设备的精度保证。[^care-martin-faq][^humidity-taylor]

环境记录可以帮助描述变化，却不能判断裂缝是否自行复原。可见裂缝或琴桥翘起要交维修师，不继续上弦；不要以增加湿度代替结构维修。[^care-yamaha-storage]

## 图示与操作步骤

> 器材边界：仅做本页明确允许的观察和基础维护。琴颈调节杆、弦枕加工、品丝打磨、琴颈角度与结构修复交给合格维修人员；出现阻力、异常张力、结构裂缝或琴桥翘起时停止操作，不强扭、撬拔或继续上弦。[^care-yamaha-booklet][^care-yamaha-storage]

这组完整门槛是本站保守安全规则；来源支持专业处理类别与琴桥翘起不继续上弦，不是逐字列出全部触发项。下表是本站原创维护决策整理，不是品牌设备推荐或通用修复方案。

| 情境           | 型号无关默认                                                                   | 记录或核对                                                                       | 停止或求助                                               |
| -------------- | ------------------------------------------------------------------------------ | -------------------------------------------------------------------------------- | -------------------------------------------------------- |
| 弹奏后汗污     | 用适合乐器的干软布轻擦[^care-yamaha-basic]                                     | 留意布是否清洁及无硅成分                                                         | 不靠油剂或钢丝绒处理顽固污渍                             |
| 材料或漆面不明 | 不自行加入清洁剂                                                               | 查具体琴型制造商说明                                                             | 资料缺失问制造商或维修师                                 |
| 环境湿度       | 用湿度计记录室内或琴盒实测[^humidity-taylor]                                   | 日期、地点、读数与变化                                                           | 不把琴盒视为自动恒湿                                     |
| 目标范围       | 遵循具体琴型说明                                                               | Martin 与 Taylor 的 45–55% RH 仅为品牌建议例[^care-martin-faq][^humidity-taylor] | 不当所有琴的精确通用标准或设备精度保证                   |
| 存放与可见损伤 | 放保护琴盒，避热源、风口、日晒与热车[^care-yamaha-storage][^care-yamaha-owner] | 温湿变化及可见结构现象                                                           | 裂缝或琴桥翘起交维修师，不继续上弦[^care-yamaha-storage] |

先稳定放置琴体，再用干软布轻擦可及表面，不为去掉顽固污渍增加摩擦或使用未确认的用品。收纳位置避开热源、风口、日晒和热车；温湿极端或骤变都不适合作为存放条件。[^care-yamaha-owner][^care-yamaha-storage] 是否松弦也查具体琴型说明，不套用统一转向或圈数。

原创记录格式可以写：“日期／琴型／实测地点／湿度读数／环境变化／可见现象／查到的型号说明／下一步”。琴盒读数与室内读数分开标记，不把地点不同的值混成一个结果。看到读数变化时先核对资料，不直接购买设备或推断损伤原因。

## 常见错误及修正

把别人使用的保养品当所有材料通用，会跳过漆面与指板差异。修正是保持干软布默认，资料不明就停止新增用品。官方品牌说明有差异时，依据自己具体琴型查询，不用多数表决产生一个维护配方。

把琴放进盒里就停止观察，会漏掉环境变化；修正是注明实测地点并保留记录。湿度设备的存在不能保证琴不会损坏，读数也不能证明已有裂缝被修好。可见损伤应转维修师评估，而不是自行复湿试修。

## 分级练习

以下为本站原创情境练习，不要求把琴暴露在极端环境；不确定时退回资料核对，有警讯即停止。

### 第一级：辨认材料与环境

用纸面情境区分“弹后汗污”“漆面不明”“琴盒靠近热源”“可见裂缝”。为每个情境选择干布、查说明、改变存放位置或转维修师，不实际制造风险。

### 第二级：建立可核对记录

按原创格式填写现有环境观察，注明湿度计读数来自室内还是琴盒。没有测量就写“未测”，没有型号资料就写“待确认”，不以品牌示例填入自己的实测栏。

### 第三级：提出存放方案

找到具体型号资料后，写出保护琴盒的位置与环境核对方式，以及资料不足或结构警讯时的求助行动。方案不含统一温湿阈值、设备寿命保证或 DIY 修复；无法确认时停止新增维护措施。

## 自我检查标准

- 我能说明干软布默认及资料不明时不自行加入清洁剂。
- 我的环境记录注明日期、地点与实测读数，未测项不会伪填。
- 我知道 45–55% RH 是 Martin 与 Taylor 的品牌建议例，不是所有琴或设备的精度保证。
- 我能选择避开热源、风口、日晒与热车的存放位置。
- 我知道裂缝或琴桥翘起交维修师，不继续上弦或自行复湿试修。
