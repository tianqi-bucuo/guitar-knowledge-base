# 分解和弦基础

## 学习目标与先修知识

请先完成 [[03-节奏系统/09-六八拍伴奏|六八拍伴奏]]，能说出稳定脉冲并根据和弦图避开标为 `x` 的弦。本页目标是让和弦音按顺序分别发声，逐一核对目标弦、口数与拨弦手分工。

完成后，你应能区分分解和弦与同时扫响，并在声音、拍点或动作开始失控时退回单独拨弦。

## 核心概念

和弦可以让多个音同时出现，也可以把组成音依次弹出；后者就是本页所说的分解和弦。[^arpeggio-fender] 依次发声不等于让前一个音立刻消失：只要当前和弦按得清楚，各音可以自然延续并形成连续和声。

本页采用拇指、食指、中指、无名指的起步分工，但这只是本站教学安排，不是唯一正确指法。拨弦手负责找到目标弦，按弦手保持当前和弦清楚；左手演奏者按这两个动作角色镜像即可。

## 图示与操作步骤

下面是本站原创练习。使用 C 和弦时，第五弦作为低音，随后依次拨第三、二、一弦；表格不是外部 TAB 或歌曲片段。

| 项目   | 内容            |
| ------ | --------------- |
| 口数   | `1 2 3 4`       |
| 琴弦   | `5 3 2 1`       |
| 拨弦手 | `拇 食 中 无名` |

1. 先不按和弦，指认第五、三、二、一弦，并依次说出负责的手指。
2. 用 [[02-和弦系统/04-C和弦|C和弦]] 组形，从第五弦开始逐弦检查，确认四根目标弦都清楚。
3. 说 `1 2 3 4`，每个口数只拨表中对应的一根弦；不把动作扩大成扫弦。
4. 让已拨响的音自然延续。若后一指碰停前一根弦，缩小移动并重新核对目标弦。

## 常见错误及修正

- **四根弦几乎同时响：** 把动作缩回单弦，听见当前音头后再移向下一根弦。
- **低音弦选错：** 每次开始前先读和弦图；当前 C 型从第五弦开始，不把第六弦加入练习。
- **拨弦后手指远离弦面：** 回到相近准备位置，减少下一次重新寻找目标的距离。
- **为保留延音而持续加大按弦压力：** 按弦手只维持清楚发声所需的压力，延音不靠继续夹紧获得。

## 分级练习

### 一级：隔离目标弦

不开节拍器，逐项指认弦号与手指，再拨出表中动作；每个音都要来自目标弦，出现误触就停下重新定位。

### 二级：舒适脉冲与口数

使用自己能稳定维持的舒适脉冲，开口数拍并完成同一弦序。先保持弦号准确，再观察各音是否能自然延续。

### 三级：学习者自选目标脉冲

只有当音色、拍点和放松动作都稳定时，才进入学习者自选的目标脉冲；任一项退化就退回前一阶，重新隔离出错的弦或手指。

> 安全边界：本页不用于诊断或治疗。出现疼痛、麻木或针刺感、无力、肿胀、动作控制下降或明显不适时，立即停止；症状持续、反复或加重时，请向合格医疗专业人士求助。

不适或疲劳时暂停，不用增加握持或拨弦力量换取连续性。[^safety-bapam]

## 自我检查标准

- 四个音头依次出现，没有变成一次扫弦。
- 每个口数都命中表中的目标弦，低音从第五弦开始。
- 拇、食、中、无名的动作可分别观察，手指不会在拨弦后远离准备区。
- 后一音出现时，前一音没有被无意碰停；若发生，你能指出是哪次移动造成。
