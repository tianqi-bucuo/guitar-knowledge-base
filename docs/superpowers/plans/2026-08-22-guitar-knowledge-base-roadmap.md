# 民谣吉他知识库实施路线图

本路线图把已批准的设计拆成四份按顺序执行的计划。拆分原因是平台与校验、图示生成、正文创作和发布验收可以分别评审；把它们塞进一次实现会让失败定位和内容审阅都失去边界。

1. [基础平台与内容校验计划](2026-08-22-guitar-kb-foundation-plan.md)：引入 Quartz 4.5.2，配置中文站点与 Obsidian 本地库，实现内容清单和校验 CLI，并交付可构建的种子站点。
2. [SVG 图示系统计划](2026-08-22-guitar-kb-diagrams-plan.md)：实现和弦图、指板图和节奏图的结构化数据、可复现生成器与快照测试。
3. [75 篇正文建设计划](2026-08-22-guitar-kb-content-plan.md)：建立完整清单，按十个模块研究、撰写、引用、交叉链接并验收 75 篇中文页面。
4. [发布与质量验收计划](2026-08-22-guitar-kb-release-plan.md)：完成学习依赖图、来源与版权审计、桌面和移动端检查，以及最终离线和生产构建验收。

每份计划完成后应保持网站可构建，并以一次独立评审和一组干净提交收尾。后续计划依赖前一计划明确列出的接口，不允许跳过基础校验直接批量写正文。
