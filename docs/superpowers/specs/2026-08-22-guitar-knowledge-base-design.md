# 民谣吉他知识库设计规范

日期：2026-08-22  
状态：已通过对话设计评审，待书面规范评审

## 1. 项目目标

在当前目录创建一个以简体中文编写、覆盖零基础到进阶核心阶段的民谣吉他知识库。知识库必须同时满足两种使用方式：

1. 作为本地 Markdown 知识库，可在 Obsidian 中离线编辑、阅读和浏览双向链接。
2. 通过 Quartz 4 将同一批 Markdown 内容生成可搜索、可导航的静态网站。

首版不是空目录或少量示例，而是一个可直接学习和查阅的完整版本。内容目标为约 75 篇精写页面，允许最终篇数落在 60–80 篇之间。内容以民谣吉他为主，采用国际音名与和弦记法，如 C、Dm、F♯。

## 2. 成功标准

首版完成时应满足以下条件：

- 初学者能沿学习路线从调音、姿势和基本按弦开始，逐步学习和弦、节奏、常用技巧、弹唱伴奏和基础乐理。
- 已有基础的学习者能通过目录、标签、搜索、双向链接和术语索引直接查找独立主题。
- 正文、附件和自制 SVG 图示在 Obsidian 中离线可读。
- Quartz 能完成生产构建，网站具备中文搜索、分层导航、标签、反向链接和关系图谱。
- 每篇教学文章包含明确的学习目标、先修知识、操作方法、练习、自检标准和下一步链接。
- 关键事实和教学结论附权威来源或延伸阅读，读者可以追溯依据。
- 发布内容不存在内部断链、缺失附件、重复永久链接、占位文本或未完成草稿。

## 3. 首版范围

### 3.1 包含内容

- 民谣吉他的基础结构、调音、持琴姿势和左右手基本动作。
- 开放和弦、横按和弦、常用和弦进行与转换训练。
- 节拍、拍号、节拍器、扫弦、分解和弦、切分和常见伴奏型。
- 制音、击弦、勾弦、滑音等常见民谣吉他技巧。
- 弹唱所需的选调、变调夹、段落组织和基础编配思路。
- 音名、音程、调、级数、和弦构成和基础指板认知。
- 练习安排、速度记录、错因分析、阶段测验和复盘方法。
- 基础保养、常见杂音排查、手部负担与安全边界。
- 术语、和弦、节奏型、来源和延伸阅读索引。
- 自制和弦图、指板图、节奏示意图，以及必要的外部音视频链接。

### 3.2 不包含内容

- 电吉他、古典吉他或高级爵士和声的完整课程。
- 用户账号、云同步、评论、打卡、后台服务或数据库。
- 本站录制的音频或视频课程。
- 受版权保护歌曲的完整歌词、完整曲谱或教材的大段转载。
- 网站托管账号和线上部署；首版只需生成可部署的静态网站。

以后可以为进阶乐理、演奏技术、器材维护和互动练习分别设计后续阶段，但不得借此扩大首版范围。

## 4. 技术架构

### 4.1 单一内容源

`content/` 是知识库的唯一内容源。Obsidian 直接将该目录作为本地库打开；Quartz 4 读取同一目录并生成静态网站。任何生成后的 HTML 都属于构建产物，不得手工维护。

整体数据流为：

```text
Obsidian 或文本编辑器
        ↓
content/ Markdown + SVG 附件
        ↓
内容与资源检查
        ↓
Quartz 4 生产构建
        ↓
静态网站构建目录
```

Obsidian 是推荐但非强制的本地编辑器；Markdown 文件不依赖私有数据库格式。Quartz 负责网站生成，而不是内容编辑。二者通过 Quartz 对 Obsidian 风格 Markdown 的兼容共用同一批文件。

### 4.2 建议目录边界

```text
content/                 # 唯一内容源，也是 Obsidian 本地库
  .obsidian/             # 可共享的最小 Obsidian 设置
  00-从这里开始/
  01-持琴与基础动作/
  02-和弦系统/
  03-节奏系统/
  04-演奏技巧/
  05-弹唱与伴奏/
  06-基础乐理与指板/
  07-练习与复盘/
  08-保养安全与排错/
  09-术语与参考资料/
  assets/
    diagrams/            # 可离线显示的 SVG
    images/              # 必要的自有或许可图片
data/                    # 和弦、指板等结构化图示数据
  content-manifest.yml   # 首版页面清单、模块与发布状态
scripts/                 # 图示生成与内容检查工具
tests/                   # 生成器和内容规则测试
docs/superpowers/        # 设计规范与实施计划
quartz.config.ts         # Quartz 站点配置
quartz.layout.ts         # Quartz 页面布局配置
```

实现时可以按 Quartz 4 的实际脚手架调整框架文件位置，但不得改变 `content/` 为唯一内容源这一边界。

仓库只保留保证本地体验一致所需的最小 Obsidian 设置；窗口布局、最近打开文件、缓存等设备相关状态必须忽略，避免把个人工作区状态写入版本库。

`data/content-manifest.yml` 是首版范围的权威清单。它列出每个计划页面的模块、类型、文件路径和目标发布状态。内容检查工具依据该清单判断页面是否缺失、模块是否完整，以及计划发布页面是否仍为草稿。

## 5. 信息架构与内容配额

首版以约 75 篇正文为目标：

| 模块 | 目标篇数 | 主要内容 |
|---|---:|---|
| 从这里开始 | 5 | 使用说明、学习地图、阶段测评、调音准备 |
| 持琴与基础动作 | 8 | 姿势、左右手、拨片、按弦、换弦 |
| 和弦系统 | 12 | 开放和弦、和弦转换、横按、常用进行 |
| 节奏系统 | 10 | 拍号、节拍器、扫弦、切分、常见节奏型 |
| 演奏技巧 | 8 | 分解和弦、制音、击勾弦、滑音等 |
| 弹唱与伴奏 | 8 | 选调、变调夹、编配、前奏与段落组织 |
| 基础乐理与指板 | 8 | 音名、音程、调与级数、和弦构成 |
| 练习与复盘 | 6 | 练习方法、速度记录、错因分析、阶段测验 |
| 保养、安全与排错 | 5 | 手部负担、杂音、琴弦、基础维护 |
| 术语与参考资料 | 5 | 术语、和弦、节奏与来源索引 |

最终篇数可以因主题合并或拆分而变化，但必须保持 60–80 篇，并覆盖表中全部模块。篇数统计对象是 `content-manifest.yml` 中列出的正式 Markdown 页面，包含路线页和索引页，不包含 README、模板、设计文档、附件或构建产物。

### 5.1 学习路线与百科共用内容

学习路线只负责组织学习顺序、先修条件、阶段目标和验收方式，不重复讲解词条正文。每一步链接到独立的知识词条、练习和图示。百科入口通过目录、主题、难度和标签访问同一批文章。

这样既能让初学者顺序学习，也能让有经验的读者直接检索，而且不会产生两套内容逐渐不一致的问题。

### 5.2 文件名与永久链接

本地文件和目录采用可读的中文名称。每篇页面通过 frontmatter 配置稳定的英文 `permalink`，例如：

```yaml
title: 开放和弦入门
permalink: /chords/open-chords
```

中文文件以后可以重命名，公开网址仍保持稳定。内部链接优先采用 Obsidian 的 `[[双向链接]]`，需要自然显示文本时使用链接别名。

## 6. 页面模型

每个正式页面都必须包含 `title`、`description`、`permalink`、`type`、`tags` 和 `draft`。教学文章还必须包含 `level` 和 `prerequisites`。示例如下：

```yaml
title: 开放和弦入门
description: 认识并正确按响首组常用开放和弦
permalink: /chords/open-chords
type: lesson
level: 入门
prerequisites:
  - 正确持琴与按弦
tags:
  - 和弦
  - 左手
draft: true
```

允许的页面类型、难度值、标签和其他枚举由集中配置定义，避免同义标签和拼写漂移。路线页、索引页和术语页使用与其 `type` 对应的专门字段规则，不强制填写只对教学文章有意义的难度与先修知识。

每篇教学文章采用统一正文结构：

1. 学习目标与先修知识。
2. 核心概念。
3. 图示与操作步骤。
4. 常见错误及修正。
5. 分级练习。
6. 自我检查标准。
7. 下一步与相关词条。
8. 参考来源与延伸阅读。

练习必须尽可能给出可观测标准，如建议节拍器速度范围、连续正确次数、练习时长或音色检查项，避免只写“多练习”。不同类型的索引页可以使用专门模板，但仍需满足元数据和链接规则。

## 7. 图示系统

常用和弦、指板位置等重复性图示由结构化数据驱动生成，以保证弦序、品位、指法编号、配色和尺寸一致。生成工具输出 SVG，生成后的文件也保存在知识库中，使 Obsidian 无需运行任何工具即可离线显示。

SVG 必须满足：

- 线条、色彩和字体风格统一。
- 不能只用颜色区分状态，同时提供符号或文字。
- 包含可读的标题或替代文字，便于无障碍阅读。
- 与生成它的结构化数据保持可追溯关系。

不适合数据化的特殊节奏或动作示意图可以单独制作，但必须遵守相同的视觉和无障碍约定。

## 8. 来源、版权与安全政策

### 8.1 来源

关键事实、教学原则、人体工学和安全建议使用权威来源。正文通过脚注引用，并记录来源标题、发布机构或作者、链接和访问日期。每篇末尾提供简短的参考来源与延伸阅读，不让引用打断主要学习流程。

一般教学表达必须用自己的语言重新组织。无法确认的说法不作为事实发布；多个可靠来源有分歧时，应明确说明适用条件，而不是武断选择一个结论。

### 8.2 版权

曲目应用示例只使用原创练习、公版素材或符合法律与许可要求的短小引用。不得收录受版权保护歌曲的完整歌词、完整曲谱、完整编曲或教材大段内容。外部音视频以链接为主，不复制其媒体文件。

### 8.3 安全

关于手部、手腕和肩颈负担的文章只能提供一般性练习安全建议。内容应提醒读者在疼痛、麻木或持续不适时停止练习，并向合格专业人士求助；不得把知识库描述为医疗诊断或治疗方案。

## 9. 编辑与发布流程

1. 从相应页面模板创建 Markdown 文件。
2. 填写 frontmatter，保持 `draft: true`。
3. 编写正文、图示、练习、关联词条和来源。
4. 生成或更新所需 SVG。
5. 运行结构、链接、资源和内容完整性检查。
6. 在 Obsidian 中检查离线阅读体验。
7. 使用 Quartz 本地预览代表性页面。
8. 通过检查后取消草稿状态。
9. 执行 Quartz 生产构建并完成发布前验收。

构建应保持离线可重复。外部网址可用性检查独立运行，临时网络故障只产生报告，不阻断本地生产构建；内部链接和本地资源错误必须阻断构建。

## 10. 错误处理

内容检查工具必须输出具体文件路径、规则名称和可执行的修复提示。发现以下问题时应返回非零状态并阻止发布：

- 必填元数据缺失或枚举值无效。
- 标题、别名或永久链接重复。
- 内部链接、嵌入、图片或附件目标不存在。
- SVG 无法解析、缺少文字说明或依赖的数据不存在。
- 正式页面仍含 `TODO`、`TBD`、空章节等占位内容。
- 教学页缺少练习、自检标准或参考来源。
- 计划发布的页面仍处于草稿状态。
- Quartz 生产构建失败。

外部链接失效在独立报告中列出页面、链接和响应情况，由维护者判断是更新、替换还是保留历史来源。

## 11. 验证策略

### 11.1 自动验证

- 元数据模式、允许的难度和标签校验。
- 内部链接、附件和嵌入解析。
- 标题、别名和永久链接唯一性检查。
- 占位符与必需章节检查。
- 图示数据校验及代表性 SVG 快照测试。
- Quartz 生产构建。
- 构建结果中首页、学习路线、代表性词条和搜索索引存在性检查。

### 11.2 内容验证

- 调音、音名、和弦指法、节拍与乐理术语跨文章一致。
- 练习的速度、时长和完成标准合理且无明显矛盾。
- 关键结论能追溯到页面所列来源。
- 学习路线中每个先修知识都已在更早阶段覆盖。
- 相关词条形成有效链接，不产生孤立核心页面。

### 11.3 人工验收

- 在 Obsidian 中离线打开内容和 SVG。
- 在桌面与手机尺寸检查首页、路线页、长文页、图示页和索引页。
- 抽查中文全文搜索、标签、双链、反向链接和关系图谱。
- 检查浅色与深色主题下的图示可读性。
- 确认首版正文总数为 60–80，并覆盖全部十个模块。

## 12. 实施边界与顺序

实施计划应将工作拆为可独立验证的阶段：

1. 建立 Quartz 与 Obsidian 兼容的最小项目骨架。
2. 定义元数据、模板、标签和内容检查规则。
3. 实现图示数据格式、SVG 生成器与测试。
4. 建立完整目录、学习路线和词条清单。
5. 按模块编写并交叉链接 60–80 篇内容。
6. 补齐来源、图示、索引和跨文章一致性检查。
7. 完成 Quartz 构建、搜索、移动端与 Obsidian 离线验收。

任何互动式节拍器、账号功能、云同步、本站音视频或其他乐器分支都需要新的设计评审，不应在本项目中顺带加入。

## 13. 技术选择依据

- Quartz 4 官方文档：<https://quartz.jzhao.xyz/>
- Obsidian 兼容性：<https://quartz.jzhao.xyz/features/Obsidian-compatibility>
- Quartz 全文检索：<https://quartz.jzhao.xyz/features/full-text-search>

Quartz 4 适合本项目的关键原因是：直接处理 Markdown，兼容 Obsidian 风格双链，提供反向链接、关系图谱和对中文友好的全文检索，同时无需后台服务。
